## 导出步骤

1. 在 Obsidian 中打开对应的 `.excalidraw.md` 文件
2. 右上角「更多选项」→ Switch to EXCALIDRAW VIEW
3. 左下角菜单 → Export image → PNG（Scale 2x）
4. 保存在本目录
