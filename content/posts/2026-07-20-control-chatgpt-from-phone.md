做「算一卦」小程序时，很多工作并不是敲完一条指令就立刻结束。云函数需要部署，大模型报告需要等待，页面修改后还要重新构建，AI 也可能在中途询问方向或等待授权。

如果我必须一直守在电脑前，AI 虽然加快了执行，人的时间仍然会被等待切碎。

真正改变节奏的，是把手机接入电脑上正在运行的 ChatGPT/Codex 任务：出门后继续看进度，遇到分叉时给出判断，需要确认时及时放行，想到新约束时随手补充。电脑继续提供项目文件、开发环境和工具，手机只负责沟通与控制。

**手机不是第二台开发机，而是主机上 AI Coding 会话的控制面。**

这个思路来自卡兹克分享的[远程操控 Agent 方案](https://x.com/Khazix0918/status/2077615013913883003)。他的组合很清楚：Codex Remote 负责大多数对话式协作，完整桌面远控负责扫码、登录和复杂图形界面等兜底场景。本文在这个思路上，结合 OpenAI 当前官方流程和我自己的使用经验，整理一套更容易复用的做法。

## 先分清两种远程控制

远程使用 AI Agent，实际包含两种完全不同的能力。

第一种是 **Agent 远程协作**。你在手机 ChatGPT App 的 Remote 页面进入主机上的任务，可以继续对话、回答问题、审批操作，查看截图、终端输出、代码差异和测试结果。手机看到的是任务上下文，不是被压缩到小屏幕里的整个电脑桌面。

第二种是 **完整桌面远控**。手机直接显示电脑桌面，像远程鼠标和键盘一样操作系统。这种方式适合扫码登录、处理验证码、切换不支持 Remote 的软件，或者完成必须精确点击的图形界面操作。

日常应当以前者为主，因为它更适合阅读和决策；后者只做兜底，因为完整桌面权限更大，在手机上操作也更费力。

参考文章使用的是“Codex 主力 + 网易 UU 远程兜底”。这里真正值得复用的不是某一个产品名，而是这套双层结构：

**任务协作层负责持续推进，桌面控制层负责处理协作层碰不到的最后一公里。**

### 当前官方方案能做什么

OpenAI 的 Remote 会把手机连接到运行 ChatGPT 桌面应用的 Mac 或 Windows 主机。连接后，你可以从 iOS 或 Android：

- 在主机已有项目中新建或继续任务；
- 发送补充指令，回答 Agent 的问题并改变方向；
- 审批命令和其他需要确认的操作；
- 查看输出、代码差异、测试结果、终端内容和截图；
- 在任务完成或需要注意时接收通知。

项目文件、凭据、权限、插件、Skills、浏览器和 Computer Use 仍然来自那台主机。手机不会复制一套开发环境，也不会绕过原有权限。OpenAI 通过中继层连接已授权设备，不要求把本地服务直接暴露到公网。[OpenAI Remote connections](https://learn.chatgpt.com/docs/remote-connections)

这正是它适合 AI Coding 的原因：手机只传递意图、判断和授权，真正的文件读写、构建与测试仍在熟悉的电脑环境中发生。

## 五分钟完成手机配对

当前推荐入口在 ChatGPT 桌面应用里，而不是照搬旧教程中的命令行或手工配对码。

### 第一步：更新并确认账号

在电脑上更新 ChatGPT 桌面应用，在手机上更新 ChatGPT App。两台设备需要登录同一个 ChatGPT 账号和工作区。

如果手机里没有 Remote 入口，优先检查 App 是否已经更新、所在区域是否支持，以及工作区管理员是否开启 Remote Control。

### 第二步：从主机发起连接

在要作为主机的电脑上打开 ChatGPT 桌面应用：

1. 从侧边栏选择 **Set up Remote**；
2. 或进入 **Settings → Connections → Control this Mac**；
3. 开启允许其他设备连接；
4. 点击添加设备，让电脑显示配对二维码。

一次配对只连接这一台手机与这一台主机。要控制多台电脑，需要分别配对。

### 第三步：用手机扫描二维码

使用手机扫描电脑上的二维码，ChatGPT App 会打开连接流程。确认账号与工作区，完成可能出现的双重验证、SSO 或 Passkey 验证。

配对二维码是短时凭证。页面放久了、截图稍后再扫，或者中途切换账号，都可能导致失效。遇到这种情况不要反复扫旧码，直接回到电脑重新生成。

### 第四步：让主机保持可用

在 **Settings → Connections** 中打开保持唤醒选项，并确保电脑：

- 接通电源且网络稳定；
- ChatGPT 桌面应用仍在运行；
- 没有主动进入睡眠；
- 需要操作浏览器或桌面软件时，已启用对应权限与 Computer Use。

主机休眠、断网或退出应用后，手机端不会接管执行，远程任务只会等主机恢复。

### 第五步：从手机进入同一任务

在手机 ChatGPT App 中打开 **Remote**，选择刚连接的主机，再进入已有项目或任务。此时看到的是主机的实时上下文，可以继续对话，也可以在主机项目里新建任务。

OpenAI 在 2026 年 6 月已将 Codex Remote 扩展到全部 ChatGPT 方案，并采用一台移动设备与一台主机的一对一二维码配对；具体入口仍可能随版本和地区调整。[ChatGPT Release Notes](https://help.openai.com/en/articles/6825453-chatgpt-release-notes)

## 手机端最值得做的五件事

远程控制的价值不是让人在任何地方都盯着 AI，而是在少数关键节点及时介入。

### 启动耗时但边界清楚的任务

例如构建项目、整理资料、排查报错、运行测试或生成一版文档。任务可以在主机上继续执行，你只在结果出来后查看。

### 在 Agent 卡住时快速补充判断

Agent 经常不是“做不到”，而是在两个方向之间需要你选择。手机回复一句“保留现有接口，只改页面层”，就能避免它停到你回家。

### 处理权限确认

涉及安装依赖、访问浏览器或执行重要动作时，系统仍会按原有权限请求确认。远程控制不会取消这些闸门，但能让你及时看见并处理。

### 审核证据，而不是只看一句完成

优先查看测试结果、页面截图和代码差异。对部署、删除、付费和对外发布等重要动作，先让 Agent 汇总影响范围，再决定是否继续。

### 把突然出现的灵感放进正确项目

散步或通勤时想到新功能，可以直接在主机的对应项目下新建任务。上下文、规则、Skills 和依赖都留在同一台机器，不需要在手机上维护另一套配置。

## 一条适合手机输入的任务模板

手机不适合写很长的需求文档，但可以用五行把任务约束清楚：

```text
目标：解决什么问题，最终要看到什么结果。
范围：允许修改哪些页面或文件，不要碰什么。
验收：必须通过哪些测试，提供哪些截图或证据。
决策：遇到可逆小问题自行处理，方向变化先问我。
结束：完成后给出结果、风险和下一步，不要只说“已完成”。
```

它比“帮我继续处理一下”多写几十个字，却能显著减少远程沟通来回。

## 为什么还需要完整桌面远控兜底

Codex Remote 擅长围绕任务沟通，却不等于一块完整的远程显示器。

这些场景更适合临时切到完整桌面远控：

- 网站要求手机扫描电脑屏幕上的登录二维码；
- 系统弹出 Agent 无法读取或无法点击的窗口；
- 需要在微信开发者工具等桌面软件中进行精细操作；
- 要启动暂时没有 Remote 能力的本地工具；
- 需要人工确认电脑当前到底显示了什么。

参考文章选择网易 UU 远程作为这一层，也可以使用自己信任的其他远程桌面工具。无论选择哪一种，都建议开启双重验证，使用独立强密码，只授权必要设备，并在不需要无人值守时关闭相关入口。完整桌面远控拥有的权限通常比 Agent 会话更广，便利不能替代安全边界。

## 用在「算一卦」项目里的实际节奏

这次小程序开发中，远程协作最适合放在“任务执行时间长，但中途只需要少量判断”的环节。

例如，电脑上开始进行一次首页样式调整和完整构建后，我可以离开座位；手机收到问题时，确认以真机截图为准，要求保持底部按钮首屏可见；构建结束后，在手机查看结果与差异。回到电脑前，再使用微信开发者工具完成真正的模拟器和真机验收。

这套方式没有替代最后的专业工具，也没有让手机承担不适合它的精细操作。它只是让等待构建、模型生成和自动检查的时间，不再强迫人一直守在屏幕前。

## 断开连接时，按这个顺序检查

远程不可用时，不必一开始就重装所有软件：

1. 确认主机仍开机、联网，ChatGPT 桌面应用正在运行；
2. 确认电脑已允许其他设备连接；
3. 确认手机与电脑登录同一账号和工作区；
4. 更新两端 App，并重新生成二维码配对；
5. 检查电脑是否睡眠，或退出登录后忘记重新开启 Remote；
6. 企业工作区再检查管理员权限、SSO 与多重验证。

如果是“二维码已过期”，解决办法只有一个：在主机重新生成。旧二维码不应该保存、转发或反复尝试。

## 远程的意义，是减少等待，不是延长工时

手机远程控制最容易被误解成“随时随地继续工作”。我更愿意把它理解成一种减少阻塞的工具。

Agent 需要人做判断时，及时回答；任务有结果时，快速确认；必须回到电脑处理的事情，明确留到电脑前。这样手机接住的是碎片化决策，而不是把完整工作台永久塞进口袋。

从桌面到手机，真正被延伸的不是工作时间，而是一条任务上下文。规则、项目、文件和工具都留在主机上，人只在最值得介入的时刻出现。

这也是 AI Coding 工作流能够连续运转的最后一块拼图。
