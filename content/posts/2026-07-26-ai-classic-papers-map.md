# 一只猫读懂 AI 七十年：40 篇经典论文的原理与拼图

读论文最大的困难不是某一篇看不懂，而是**不知道它解决了谁的什么问题、原理和这个问题之间是什么关系**。孤立地读 Transformer，你会记得 Q、K、V，却答不上来"它为什么出现在 2017 年，而不是 1997 年"——因为答案不在公式里，在公式对症的那个问题上。

这篇文章换一个讲法。我们给自己定一个目标：

> **造一台机器，它能：看懂猫（感知）、谈论猫（语言）、画出猫（生成）、抓老鼠（决策）。**

然后带着这个目标穿越七十年。每篇论文固定讲四件事：

- **问题**：它出现时，领域卡在哪里？前一个方案为什么不行？（没有问题就没有这篇论文）
- **原理**：它具体用了什么机制？（公式与算法——关键的公式我们会**把真实数字代进去走一遍**，不让它停在符号层面）
- **为什么对症**：原理里的哪一招，正好解掉上面那个问题？（这是全文最重要的一行，是理论与问题之间的桥）
- **猫的角色**：用造猫机器打个比方，把机制和问题一起装进直觉里。

读完你会发现，40 篇论文其实只讲了一个故事：**每个原理都是为某个具体问题发明的，而每个解决方案的破绽，又孕育了下一片拼图。**

## 第一站：奠基——机器凭什么能"思考"？

**本站的中心问题**：在一切开始之前，有三个根本疑问要回答——神经活动能不能用数学描述？"智能"怎么判定？机器能不能不靠人调参、自己从数据里学？

### 1.1 神经元能计算：McCulloch & Pitts (1943)

**问题**：大脑里的神经元放电，和数学、逻辑有什么关系？如果"思考"不能被形式化，"机器智能"就无从谈起。

**原理**：提出第一个神经元数学模型——阈值逻辑单元。输入加权求和，过阈值则点火：

```
y = 1( Σᵢ wᵢxᵢ ≥ θ )
```

代个数看一眼：用它搭一个 AND 门——两个输入权重各为 1、阈值 θ=2。输入 (1,1) 时加权和 = 1×1+1×1 = 2，够到阈值，输出 1；输入 (1,0) 时加权和 = 1，差 1 不够，输出 0。就这么一个"加权求和再比大小"的装置，搭出了逻辑电路。论文证明：这种神经元组成的网络可以表达任意布尔逻辑函数。

**为什么对症**：这个模型把"神经计算"和"逻辑电路"划上了等号——智能研究从此有了一个可计算的数学对象。后面七十年的所有网络，都是这个单元的堆叠与进化。

**猫的角色**：设"有胡须"和"有尖耳朵"两个输入，这就是一个猫科检测器——一台神经元完成了一次逻辑与运算。但它不会学习，权重全靠自己调。这个"不会学"正是下一篇要解决的问题。

### 1.2 什么叫智能：Turing (1950)

**问题**："机器能否思考"的争论陷入哲学泥潭——连"思考"都定义不清，问题根本无法推进。

**原理**：这篇论文没有算法，它的机制是**换一个可操作的判据**——模仿游戏：评委隔着墙用文字与人和机器对话，若无法可靠区分，则认为机器表现出智能。

**为什么对症**：它把"什么是智能"从一个无法证伪的形而上学问题，替换成了一个可以实验检验的行为判据。这相当于定义了整张拼图的**目标函数**：此后七十年的研究，都在以某种方式逼近这个判据——今天你在 ChatGPT 对话框里做的事，本质上就是一场图灵测试。

### 1.3 第一个会学习的模型：感知机 Rosenblatt (1958)

**问题**：M-P 神经元的权重全靠人手调，遇到真实数据一筹莫展——机器能不能**自己从数据里学出权重**？

**原理**：线性分类器 + 错误驱动更新。

```
y = sign(w·x + b)
若样本 (x, y) 被分错，则更新：w ← w + η·y·x
```

代个数走一遍（设学习率 η=1）：初始 w = (0, 0)，什么都不会分。来了一只猫：特征是（耳朵尖度=2，体重=1），标签 y=+1。当前 w·x = 0，模型瞎猜判错，触发更新：

```
w ← (0,0) + 1×(+1)×(2,1) = (2,1)
```

决策边界立刻向"能把这只猫分对"的方向挪了一步。再来一条狗、再错、再挪……几十轮后边界稳稳落在两类之间。论文还给了定心丸：只要数据线性可分，有限步内必收敛。

**为什么对症**：更新的方向就是"错在哪边、就往哪边挪边界"——每条分错的样本把决策边界向正确方向推一点。"错一次、改一点"是学习的最小定义，收敛定理则保证这条路走得到头。

**猫的角色**：教它分猫和狗，特征是（体重, 耳朵尖度）。一开始乱猜，每猜错一次微调权重，几十轮后它自己找到一条直线把两类分开。

**第一次卡关**：Minsky & Papert (1969) 证明单层感知机连 XOR 都学不会——XOR 是四个点：(0,0)→0、(1,1)→0、(0,1)→1、(1,0)→1。你在纸上画画看：没有任何一条直线能把两个 1 和两个 0 分开，而单层感知机只能画直线。funding 断流，第一次 AI 寒冬。这篇"反方论文"同样标在地图上：它划定了单层模型的能力边界，也把"多层网络怎么训练"这个问题逼上了台面。

### 1.4 破关：反向传播 Rumelhart, Hinton & Williams (1986)

**问题**：XOR 的判决书上其实写了出路——单层不行，**多层**可以（两个"半平面"取交集就能围出 XOR）。但多层网络有一个致命障碍：输出层错了，中间的隐藏层各自该背多少锅？没有人知道怎么把误差"分账"到每一层的每个权重上，于是多层网络没法训练。

**原理**：链式法则把损失对输出的误差逐层回传。对第 l 层：

```
δ_l = (W_{l+1}ᵀ δ_{l+1}) ⊙ σ'(z_l)        ← 本层误差 = 下传误差 × 激活导数
∂L/∂W_l = δ_l · a_{l-1}ᵀ                  ← 权重梯度 = 误差 × 上层输出
W_l ← W_l - η · ∂L/∂W_l                   ← 梯度下降更新
```

代个数感受"分账"：假设输出层的误差信号 δ = 0.5，它回传到上一层时，要乘上连接权重 w = 2、再乘激活函数在该点的导数 σ' = 0.8，于是上一层领到的责任份额 δ = 2 × 0.5 × 0.8 = 0.8。**责任按"你出力多大（权重）× 你当时有多敏感（导数）"的比例精确摊派**，一层一层传下去，几百层的账一秒钟算完。

**为什么对症**：δ 递推恰好解决了"分账"问题——误差不再是一笔糊涂账，而是精确摊派到每一层每个权重。多层网络从"理论上能表达、实际上没法训"变成"可以端到端学习内部表示"，XOR 之类的非线性问题迎刃而解。这是整个深度学习大厦的地基。

**猫的角色**：网络把猫错认成狗，误差像公司追责一样逐级下发："输出层错了多少？你上一层的输入错了多少？"每层拿到自己的责任份额，各自微调。

### 1.5 传统机器学习的黄金年代

神经网络坐冷板凳的年代，统计学习撑起半边天。它们面对一个更现实的限定：**既然特征要靠人设计，那在特征给定的前提下，怎么把"学规则"这一步做到最好？** 五篇论文，各回答其中一个子问题。

**EM 算法（Dempster 1977）**——含隐变量模型的通用求解器。

- 问题：数据里混着看不见的标签（比如不知道哪条记录是猫），极大似然估计里出现一个算不出的积分，直接求解死路一条。
- 原理：交替两步直到收敛。E 步：在当前参数 θ⁽ᵗ⁾ 下算隐变量的后验分布，构造期望完全对数似然 Q(θ|θ⁽ᵗ⁾) = E_z[log p(x, z|θ)]；M 步：θ⁽ᵗ⁺¹⁾ = argmax_θ Q(θ|θ⁽ᵗ⁾)。论文证明似然单调不减。
- 为什么对症：把"不知道隐变量"这个死结，拆成两个各自能解的子问题——假装知道标签时估参数容易，假装知道参数时猜标签也容易。交替逼近，绕开了算不出的积分。
- 猫的例子：一堆猫狗体重数据混在一起，真实情况是猫约 3kg、狗约 7kg。EM 从瞎猜"两个群体都是 5kg"出发：E 步给每条记录算"属于猫的概率"（4kg 的，像猫；8kg 的，像狗），M 步按这些概率重新估计两个均值。几轮之后收敛到 3.1kg 和 6.9kg——没人告诉过它哪条是猫，群体被自动拆开。GMM 聚类、HMM、主题模型都靠它。

**决策树（Quinlan 1986/1993，ID3/C4.5）**——可解释机器学习的代表。

- 问题：希望模型学到的规则**人读得懂**，而不是一堆数字。
- 原理：递归建树，每次选择信息增益最大的特征做分裂。信息增益 = 父节点熵 − 加权子节点熵，其中熵 H = −Σ pᵢ log pᵢ。C4.5 用增益率（增益除以分裂信息）惩罚"取值过多"的特征。
- 为什么对症：信息增益把"哪个特征最有区分度"从直觉变成了可比较的数值，贪心算法每一步都在当前最优处下刀，树自然就长成了人能读的 if-else 规则。
- 猫的例子：自动长成一棵规则树："耳朵尖？→ 是 → 会爬树？→ 是 → 猫"。

**SVM（Cortes & Vapnik 1995）**——统计学习理论的高峰。

- 问题：能分开两类的直线有无数条，选哪一条在没见过的数据上最稳？非线性可分的数据又怎么办？
- 原理：在所有能分开两类的超平面中，最大化间隔（margin）：

```
min ½||w||²   s.t.  yᵢ(w·xᵢ + b) ≥ 1
```

拉格朗日对偶化后，解只依赖少数落在间隔边界上的样本——支持向量。1000 个训练样本里，可能只有 30 个真正决定边界的位置，其余 970 个全部删掉，结果一模一样。非线性问题用核技巧：用 K(x, x') = φ(x)·φ(x') 隐式计算高维内积，无需真的构造高维特征。

- 为什么对症：Vapnik 的理论早就指出"泛化能力"和间隔挂钩，SVM 把这个理论直接翻译成可优化的几何目标——离两类样本都最远的那条线，对新样本最不容易判错（想象在猫群和狗群之间修一条尽可能宽的隔离带，新来一只动物落在带边的概率最小）。核技巧则把"非线性"翻译成"高维里的线性"，绕开了维数灾难。它是深度学习崛起前的分类天花板。
- 猫的例子：平面上猫狗点被一条曲线分隔。核技巧相当于把点"吹"到三维空间用平面切开，回到原空间就是那条曲线。

**AdaBoost（Freund & Schapire 1997）**——集成学习开山之作。

- 问题：一堆"只比瞎猜好一点"的弱分类器，能不能组合成强分类器？理论上是否有保证？
- 原理：串行训练 T 个弱分类器。第 t 个分类器的权重 αₜ = ½ ln((1−εₜ)/εₜ)（越准权重越大）；样本权重更新 wᵢ ← wᵢ·exp(−αₜ yᵢ hₜ(xᵢ))——分错的样本下一轮被放大。最终 H(x) = sign(Σ αₜ hₜ(x))。论文给出了可证明的误差界。
- 代个数：一个错误率 ε=0.4 的弱分类器，话语权 α = ½ln(1.5) ≈ 0.2；而一个 ε=0.1 的，α ≈ 1.1——准头的差距被对数放大成话语权的 5 倍差距。
- 为什么对症：样本权重放大机制强迫每一个新分类器**专攻前一个的盲区**——错误被逐个击破，而不是平均分摊。这是"弱变强"从猜想变成定理的关键。
- 猫的例子：第一轮"有无胡须"分对 60%；第二轮专攻上轮分错的样本……100 个 60% 的"臭皮匠"加权投票后达到 99%。

**随机森林（Breiman 2001）**——集成的另一极，至今是表格数据的强基线。

- 问题：单棵决策树长得越深越容易过拟合——对训练数据里的噪声也照单全收，换一批数据表现就崩。
- 原理：与 AdaBoost 的串行纠错相反，它走并行降方差路线。Bagging：每棵树用自助采样（有放回抽样）的一部分数据训练；随机特征子空间：每个分裂节点只从随机抽取的 ≈√d 个特征里选最优。最终多数投票。
- 为什么对症：过拟合在统计上就是"方差大"。多个模型取平均能降方差，但前提是它们犯的错不一样——双重随机性（随机样本 + 随机特征）正是为了压低树与树之间的相关性，让平均真正有效。想象问 500 个人同一个问题：如果他们都抄同一份参考答案，问多少人也没用；只有各自独立判断，平均才接近真相。
- 猫的例子：预测一只猫的身价。500 棵树各自看随机的 70% 样本和随机几个特征（体重、毛色、品种……），各自出价取平均——单棵树容易过拟合，平均后稳得多。

这条路线留下的遗产至今有效：间隔、正则化、集成、偏差-方差权衡。但天花板也清楚——**特征要人设计**，而"猫"的特征，人设计不全。这个天花板，就是第二站要砸碎的东西。

## 第二站：看懂猫——深度学习的视觉革命

**本站的中心问题**：传统方法的上限是"人设计特征、机器学规则"，而"猫"的特征人根本设计不全。能不能让网络**直接从像素里自己学出特征**？这带来两个子问题：网络结构该长什么样（2.1–2.4）？深网络怎么才能训得动（2.5）？

### 2.1 卷积神经网络：LeNet-5（LeCun et al., 1998）

**问题**：全连接网络直接把像素当输入有两个死结——参数量爆炸（一张 256×256 的图约 6.5 万个输入，每个都连所有神经元，一层就要几十亿参数）；而且完全不利用图像的结构：猫在左上角和右下角，对它来说是两组毫不相关的数字。

**原理**：利用图像的两个先验——局部性（相邻像素相关）与平移不变性（猫在左上角还是右下角都是猫）。

- **卷积**：一个小卷积核（如 5×5）在整张图上滑动做内积，同一核共享权重 → 参数量从全连接的 O(W·H) 降到 O(k·k)，且天然平移等变；
- **池化/子采样**：局部取平均或最大，压缩尺寸、引入轻微平移不变性；
- **层级抽象**：低层响应边缘，中层响应纹理与部件，高层响应整体构型。

代个数：一个 5×5 卷积核只有 25 个参数，扫完整张 256×256 的图还是这 25 个；换成全连接，同样一层要 6.5 万×6.5 万 ≈ 43 亿个参数。这就是"共享权重"的威力。再比如一个竖直边缘检测核 `[-1, 0, 1]`：扫过纯色区域时左右抵消、输出 0；扫到猫耳朵的轮廓线时左右明暗突变、输出一个很大的数——第一层网络就这样自己学会了"哪里有边"。

LeNet-5 结构为 C1–S2–C3–S4–C5–F6–输出，全程用反向传播训练，在银行支票手写数字识别上首次完整落地。

**为什么对症**：共享权重这一招同时解掉两个死结——参数量骤减让训练可行；而"同一个核扫全图"意味着"在哪里都是猫"这个性质变成了结构自带的，不用再学。特征第一次不是人设计的，而是网络自己学出来的。

**猫的角色**：第一层卷积核只认"弧线""尖角"这种小笔画，中间层认出"尖耳朵""胡须"的组合，最后一层判断"这是猫的构型"。

### 2.2 革命发令枪：AlexNet（Krizhevsky, Sutskever & Hinton, 2012）

**问题**：LeNet 证明了方向，但 14 年来没人能把 CNN 做大做深——卡在四个现实瓶颈上：深了梯度消失训不动、算力不够、数据不够、一过拟合就白搭。

**原理**：把 LeNet 放大到 5 卷积层 + 3 全连接层、6000 万参数，并用四个工程决策逐一拆掉上述瓶颈：

1. **ReLU 激活** f(x) = max(0, x)：导数恒为 1，缓解 sigmoid/tanh 在深处的梯度消失，训练速度快 6 倍。看数字：sigmoid 在输入 |x|=4 时导数只有约 0.018，十个这样的层连乘，梯度只剩 10⁻¹⁷——信号死了；ReLU 在正区间导数永远是 1，连乘多少次都不衰减；
2. **GPU 并行**：拆到两张 GTX 580 上训练，层间在特定位置通信；
3. **Dropout**（见 2.5）：全连接层以 0.5 概率随机失活，抑制过拟合；
4. **数据增强**：随机裁剪、水平翻转、颜色抖动，把训练集变相扩大数千倍。

结果：ImageNet 竞赛 top-5 错误率 15.3%，碾压亚军（26.2%）约 11 个百分点——上一届冠亚军的差距通常只有零点几个百分点，这个幅度等于别人百米跑 10 秒 5，他直接跑进 9 秒。整个领域自此转向深度学习。

**为什么对症**：注意这四招和四个瓶颈是**一一对应**的——ReLU 对梯度消失、GPU 对算力、增强对数据量、Dropout 对过拟合。AlexNet 没有发明新理论，它证明的是"瓶颈全部可拆"，于是"端到端学出来的特征全面碾压人设计的特征"。此后"特征工程"这个工种在视觉上消亡。

**猫的角色**：前一届冠军靠手工 SIFT 特征 + SVM，等于人先把"猫长什么样"总结成规则再让机器匹配；AlexNet 把这一步也交给了网络——这正是在砸第一站留下的那块天花板。

### 2.3 网络能堆多深：VGG 与 GoogLeNet（2014–2015）

AlexNet 证明方向对了，但结构粗糙：卷积核多大、网络多深、每层多宽，全凭感觉。接下来两篇分别回答"深度"和"宽度/尺度"怎么设计。

**VGG（Simonyan & Zisserman, 2014）**——统一 3×3 小核一路堆到 16–19 层。

- 问题：大卷积核（7×7、11×11）又贵又糙，深度和感受野之间怎么权衡？
- 原理：两层 3×3 卷积堆叠的感受野等于一层 5×5，三层等于 7×7，但参数更少、非线性更多。代个数（设通道数 C=64）：一层 7×7 要 7²×64² ≈ 20 万参数；三层 3×3 只要 3×3²×64² ≈ 11 万——同样的视野，参数省一半，中间还多两次非线性变换。
- 为什么对症：用"堆小核"替代"用大核"，同样的视野换来了更多层非线性变换（表达能力）和更少参数（可训练性）。结构规整如乐高，成为之后多年的标配骨干，也干净地证明了"深度本身有效"（控制变量法的典范，见 7.5）。

**GoogLeNet / Inception（Szegedy et al., 2015）**——同层并行多尺度 + 1×1 降维。

- 问题：图里的目标大小不定——猫脸占满画面和猫缩在角落，需要的"观察尺度"完全不同；而卷积层一旦加宽加深，计算量就失控。
- 原理：Inception 模块把输入同时送进 1×1、3×3、5×5 卷积和池化四条支路，输出在通道维拼接——让网络自己决定用哪个尺度；在昂贵的大卷积之前先用 1×1 卷积压缩通道数（bottleneck），计算量大降。代个数：输入 256 通道、直接做 3×3 卷积输出 256 通道，要 3²×256×256 ≈ 59 万次乘加；先用 1×1 压到 64 通道再做，只要 1×256×64 + 3²×64×256 ≈ 16 万——省约 73%。22 层深、仅 500 万参数（AlexNet 的 1/12），top-5 错误率 6.7%。
- 为什么对症："尺度不定"用并行多分支对症（不用人猜尺度，全给，让网络挑）；"计算失控"用 1×1 降维对症（先压通道再做贵的大卷积）。
- 猫的例子：VGG 像统一规格的乐高块拼高楼；Inception 像每层派 4 支侦察队分头看（细看胡须、中看脸、远看轮廓），再把情报拼起来。

### 2.4 深度瓶颈的突破：ResNet（He et al., 2015）

**问题**：既然"更深=更强"，那就使劲堆？实验却给出反直觉的结果：56 层网络的**训练误差**比 20 层还高。注意是训练误差——不是过拟合（那是测试误差高），而是更深的网络**连训练集都拟合不好**，优化本身失败了。最深的网络按理至少能退化成"浅网络 + 后面全做恒等映射"，但 SGD 连恒等映射都学不出来。

**原理**：残差学习。每层不再学习目标映射 H(x)，只学残差 F(x) = H(x) − x；原始信息 x 走跨层直通车道（shortcut）：

```
y = F(x, {Wᵢ}) + x
```

反向传播时梯度可以经恒等路径无损回传：

```
∂L/∂x = ∂L/∂y · (∂F/∂x + 1)
```

代个数看那个"+1"有多重要：假设每层局部梯度因子是 0.9，没有残差时 50 层连乘后是 0.9⁵⁰ ≈ 0.005——第一层的梯度只剩千分之五，基本收不到信号；有了 +1，每层的梯度因子至少是 0.9 + 1 = 1.9 ≥ 1，传 50 层还是满血。

结果：152 层网络，ImageNet top-5 错误率 3.57%，首次超越人类水平（约 5.1%）。

**为什么对症**：那个"+1"就是全部答案——梯度至少能原样传回，不随层数连乘衰减；而"默认什么都不做、只学增量"让恒等映射从"要学出来的目标"变成了"不学的默认值"。优化失败的对症药不是更好的优化器，而是换一个更好优化的**问题形式**。残差连接从此成为所有深网络（包括 Transformer）的标配。

**猫的角色**：像编辑改稿——与其让每层把文章重写一遍，不如只标注"修改意见"，原文原样传递。深度自此不再是约束，而成了资源。

### 2.5 两块看不见的基石和一台发动机

深网络能训起来，除了结构，还靠这三样"看不见的基础设施"。它们各自针对训练崩溃的一种病因。

**Dropout（Srivastava et al., 2014）**——针对过拟合。

- 问题：网络越大越"过目不忘"，把训练集的噪声也背下来，新数据上翻车。
- 原理：训练时每个神经元以概率 p 被"关掉"（输出置零）；测试时全体参与、权重乘以 p（或训练时用 inverted dropout 反向缩放）。数学上等价于对 2ⁿ 个共享权重的子网络做了近似模型平均——1000 个神经元的层，相当于训练了 2¹⁰⁰⁰ 个不同的网络再投票。
- 为什么对症：随机失活使任何神经元都不能依赖某个特定同伴的存在——网络被迫把知识冗余地分布存储，这正是"集成能抗过拟合"的机理，但成本只是训练一个网络。
- 例子：团队每次开会随机缺席一半人，每个人都得独当一面——整个团队因此更鲁棒。

**Batch Normalization（Ioffe & Szegedy, 2015）**——针对训练不稳。

- 问题：深层网络里，前面层参数一变，后面层的输入分布就跟着漂移（内部协变量偏移）——后层永远在追一个移动靶，学习率不敢开大，训练又慢又易发散。
- 原理：对每个 mini-batch 的层输入做标准化，再学一对缩放平移参数恢复表达能力：

```
x̂ = (x − μ_B) / √(σ²_B + ε)
y = γ·x̂ + β
```

- 代个数：这一层的输入原本乱七八糟（均值 47、方差 900），标准化后变成均值 0、方差 1 的"标准地形"，再经 γ、β 调整。下一层无论前面怎么折腾，拿到的都是同样规格的地形。
- 为什么对症：逐层标准化把"移动靶"钉成"固定靶"——每层都在水平地面上施工，学习率因此可以大一个数量级；γ、β 两个可学参数则保证标准化不会损失表达能力（需要时可以把分布学回去）。

**Adam（Kingma & Ba, 2014）**——针对优化难调。

- 问题：SGD 用同一个学习率走天下：梯度大的方向震荡，梯度小的方向龟速；鞍点附近更是动弹不得。每个任务调学习率像玄学。
- 原理：同时维护梯度的一阶矩（动量）和二阶矩（自适应步长），并做偏差校正：

```
mₜ = β₁mₜ₋₁ + (1−β₁)gₜ        （方向惯性）
vₜ = β₂vₜ₋₁ + (1−β₂)gₜ²       （梯度尺度）
θ ← θ − η·m̂ₜ/(√v̂ₜ + ε)
```

- 代个数：参数 A 的历史梯度一直是 ±10（v 大），参数 B 一直是 0.01（v 小）。SGD 给两者同样的步长：A 震荡、B 龟速。Adam 里步长除以 √v：A 的步长被压小，B 的被放大——陡坡小步走、平地大步走，各走各的节奏。
- 为什么对症：一阶矩给优化加"惯性"，冲过小坑洼和鞍部；二阶矩给**每个参数单独调步长**。默认 β₁=0.9、β₂=0.999 几乎免调参，至今是所有大模型的默认优化器（或其变体 AdamW）。

### 2.6 后话：CNN 被"报复"

**ViT（Dosovitskiy et al., 2020）**

- 问题：CNN 的局部性、平移先验是助力也是天花板——先验帮你在小数据上起步，但也限制了模型的表达能力上限。数据足够多之后，能不能**扔掉全部视觉先验**，让通用架构纯靠数据学？
- 原理：把 224×224 图像切成 196 个 16×16 patch，每个 patch 线性投影成向量，加位置编码，送入标准 Transformer 编码器（结构见第三站），用 [CLS] token 做分类。卷积先验全部抛弃，靠 JFT-300M 级数据硬学出来，结果超越 CNN。
- 为什么对症：patch 化把图像"翻译"成和文字同构的 token 序列——于是 NLP 那边已经被验证过无数次的 Transformer 全家桶（自注意力、残差、LayerNorm）可以原封不动搬过来用。先验缺的课，用数据规模补。
- 猫的角色：196 个 patch 像 196 个"视觉单词"，模型像读句子一样读图，靠 patch 间注意力知道"猫耳朵"和"猫尾巴"属于同一只猫。

**SAM（Kirillov et al., 2023）**

- 问题：分割模型每换一类目标就要重新收集标注、重新训练——"分割一切"靠专模专用永远做不到。而且分割的训练数据（掩码）本身极贵，从哪来？
- 原理：三段式架构：重量级 ViT 图像编码器（每张图只跑一次）+ 提示编码器（点/框/文本编码为向量）+ 轻量掩码解码器（交叉注意力融合图像与提示，实时输出掩码）。训练靠"数据引擎"：模型辅助标注 → 人工修正 → 重训，滚动积累出 SA-1B 数据集（1100 万图、10 亿掩码）。
- 为什么对症：把"分割什么"从训练时的类别表变成推理时的**提示输入**——任务定义从"为每类训一个模型"变成"给一个通用模型下指令"，零样本泛化由此而来；数据引擎则对症"掩码贵"：让模型先标、人只改，标注效率提升一个数量级（这个飞轮思想见 7.2）。
- 猫的角色：街景图上点一下行人就抠出完整轮廓，再点一下猫又抠出猫——无需为每个类别单独训练。

## 第三站：谈论猫——从词向量到 Transformer

**本站的中心问题**：文字是离散符号，机器怎么算？这条线分三步推进：词先变成有意义的数字（3.1）→ 序列要能记住长距离信息（3.2–3.3）→ 把"记忆+查找"统一成一个可并行的架构（3.4–3.5）。

### 3.1 前提：词怎么变成数字——word2vec 与 GloVe（2013–2014）

**word2vec（Mikolov et al., 2013）**

- 问题：one-hot 编码里每个词都是一个孤立维度——5 万词表里，"猫"是第 1024 个位置为 1 的向量，"犬"是第 38921 个位置为 1 的向量，两者点积为 0；"猫"和"汽车"的点积也是 0。词与词之间没有任何语义，更谈不上计算。
- 原理：一个假设——词的含义由上下文决定（"近朱者赤"）。两种结构：CBOW 用上下文词预测中心词，Skip-gram 反过来。训练目标是最大化上下文出现概率；为避免对全词表算 softmax（5 万类分类，每个词都算一遍太贵），用**负采样**近似：把问题变成"真词对 vs 随机噪声词对"的二分类：

```
L = log σ(v'ₒ·vᵢ) + Σ_{k 个负样本} log σ(−v'ₖ·vᵢ)
```

代个数：正样本（"猫", "喵"）的点积是 2.0，σ(2.0) ≈ 0.88；随机采 5 个负样本（"猫", "汽车"）之类，点积压到 −1.5，σ(1.5) ≈ 0.82。每次更新只做 6 个二分类，而不是一次 5 万类分类——便宜了几千倍。再辅以高频词亚采样（"的""了"随机丢弃）。

- 为什么对症："用上下文预测词"这个任务**不需要任何标注**——文本本身就是标签，于是语义学习第一次可以在全互联网语料上跑起来；而词向量作为副产品，天然把语义编码成了几何结构：相似的词在空间上靠近，关系变成方向。
- 猫的例子：`vec("猫") − vec("小猫") + vec("狗") ≈ vec("小狗")`。"物种→幼崽"这个关系被编码成了向量空间里的一个固定方向——做向量加减法就能玩"类比推理"，这是语义第一次变成算术。

**GloVe（Pennington et al., 2014）**——全局统计路线。

- 问题：word2vec 只看局部滑动窗口（前后 5 个词），全语料的整体共现统计被浪费了。
- 原理：直接利用全语料的共现矩阵 Xᵢⱼ，让词向量点积去拟合共现次数的对数：

```
J = Σ f(Xᵢⱼ)(wᵢᵀw̃ⱼ + bᵢ + b̃ⱼ − log Xᵢⱼ)²
```

f 是加权函数，压低过频与零共现项。

- 为什么对症：既然"语义藏在共现统计里"是词向量的根基，那就跳过窗口、直接对全局统计做回归——小语料上更稳，信息利用更充分。

### 3.2 机器怎么读长句子：LSTM（Hochreiter & Schmidhuber, 1997）

**问题**：RNN 按顺序读句子，理论上能携带前文信息，但实际上**误差每回传一步就乘一次激活导数**。代个数：若每步乘 0.9，50 步后剩 0.9⁵⁰ ≈ 0.005；若每步乘 0.5，50 步后是 10⁻¹⁵——梯度消失，句首的信息根本传不到句尾，长距离依赖学不到。

**原理**：核心是一条"细胞状态"信息高速公路 cₜ，配合三个 sigmoid 门控（输出 ∈ [0,1]，相当于开关旋钮）：

```
fₜ = σ(W_f·[h_{t-1}, xₜ])    遗忘门：旧信息留多少
iₜ = σ(W_i·[h_{t-1}, xₜ])    输入门：新信息进多少
cₜ = fₜ ⊙ c_{t-1} + iₜ ⊙ tanh(W_c·[h_{t-1}, xₜ])   细胞状态更新（加法！）
oₜ = σ(W_o·[h_{t-1}, xₜ])    输出门：向外暴露多少
hₜ = oₜ ⊙ tanh(cₜ)
```

把"The cat, which already ate all the fish, was full."走一遍：读到 cat 时，输入门开（≈0.9），"主语=cat、单数"被写进 cₜ；接下来 7 个插入语单词，遗忘门保持 ≈1.0（旧信息全留）、输入门关到 ≈0.1（插入语几乎进不来）——cₜ 像传送带一样把"cat、单数"原样运过 8 步；读到 was 时，输出门打开，存了半句的信息被放出来，模型据此选对单数形式。

**为什么对症**：关键就在细胞状态的更新是**加法**而非乘法——连乘路径上梯度每步衰减，而加法通道上梯度可以无损流过几十上百步（和 ResNet 的"+1"是同一思想，早了 18 年）。门控则让网络自己学会"什么该记、什么该忘"。LSTM 由此统治序列建模整整 20 年。

**猫的角色**：遗忘门让"主语=cat、单数"这条信息穿过长长的插入语，直达句尾的 was——就像快递员走高速，中间的收费站（门控）只放行、不收费（不衰减）。

### 3.3 端到端翻译与注意力的诞生：Seq2Seq + Attention（2014）

**Seq2Seq（Sutskever et al., 2014）**

- 问题：机器翻译传统上是多模块流水线（对齐、短语调表……），能不能端到端？
- 原理：两个 LSTM——编码器把源句压成一个定长向量，解码器从它逐词生成译文。首次证明端到端神经翻译可行。
- 破绽（新问题）：整句话的信息要塞进**一个定长向量**。一句 50 个词的话，不管多长，都得压进同样大小的向量——像要求你用一条 140 字的短信复述一整页纸，句子越长丢得越多。这个瓶颈直接催生了下面这篇。

**Bahdanau 注意力（Bahdanau et al., 2014）**——破关者，Transformer 的直接前身。

- 问题：就是上面的定长瓶颈——为什么非要解码器"背"下全句？人翻译时是回头看原文的。
- 原理：解码器每生成一个词，回头对编码器所有隐状态打分、加权求和：

```
eᵢⱼ = a(s_{i-1}, hⱼ)          对齐打分（小型前馈网络）
αᵢⱼ = softmax(eᵢⱼ)            归一化为注意力权重
cᵢ = Σⱼ αᵢⱼ·hⱼ                上下文向量 = 加权求和
```

代个数：翻译"猫追老鼠，因为它饿了"，生成 because 时打出的注意力权重是 α = [因为: 0.7, 它: 0.1, 饿: 0.08, 其余: 0.12]——上下文向量 cᵢ 有 70% 来自"因为"的隐状态；生成 it 时，权重变成 α = [猫: 0.65, 老鼠: 0.2, 其余: 0.15]。每一步的目光都落在原文最相关的词上。

- 为什么对症：信息不再压缩进一个向量，而是**留在原处、用时查找**——瓶颈从"记忆容量"转移到了"检索能力"，而检索（softmax 加权）是可微的、可以跟着任务一起学。这个"查询—打分—加权求和"的范式，就是三年后 Transformer 的全部内核。
- 猫的例子：像人翻译时目光在原文相关处停留，而不是闭眼背全文。

### 3.4 宇宙中心：Transformer（Vaswani et al., 2017）

**问题**：注意力很好用，但 2014–2017 年的用法是"RNN 为主、注意力为辅"——而 RNN 的串行本质还在：信息必须一个词一个词地传递，长距离衰减依旧；更要命的是**串行无法并行训练**——一个词算完才能算下一个，GPU 的并行能力用不上，数据和算力堆不上去。能不能干脆扔掉 RNN，只用注意力？

**原理**：三大件。

1. **自注意力（Self-Attention）**：每个词对全句所有词计算关联。把输入线性映射成 Query、Key、Value 三组向量：

```
Attention(Q, K, V) = softmax(QKᵀ/√d_k)·V
```

QKᵀ 算出所有词对之间的相似度矩阵（N×N），除以 √d_k 防止分数过大导致 softmax 饱和，softmax 归一化后对 V 加权求和。代个数：还是那句"猫追老鼠，因为它饿了"，"它"那一行的注意力矩阵长这样：

```
"它" 看向 →  猫    追   老鼠  因为  饿了
            0.80  0.05  0.07  0.03  0.05
```

"它×猫"那一格 0.80，一步直达——RNN 要把"猫"的信息传 4 步（猫→追→老鼠→因为→它），每步还有损耗；这里任意两个词的信息交换只需 1 步（RNN 需要 O(N) 步）。

2. **多头注意力**：把 Q、K、V 拆成 h=8 组并行计算再拼接——一个头专盯指代（它→猫），一个头盯语序，一个头盯动宾搭配（追→老鼠），各司其职。

3. **位置编码**：注意力本身不区分顺序（"猫追老鼠"和"老鼠追猫"的 QKᵀ 一样），注入正弦位置编码 PE(pos, 2i) = sin(pos/10000^{2i/d}) 告诉模型词的位置。

整体结构：每层 = 多头注意力 + 残差连接 + LayerNorm + 前馈网络 + 残差连接 + LayerNorm，堆 6 层。编码器-解码器各一叠。

**为什么对症**：自注意力把"任意两个词的信息交换"从 O(N) 步压缩到 1 步——长距离依赖问题在结构层面消失了；同时整层计算是一堆矩阵乘法，**序列维可以全并行**，训练吞吐量碾压 RNN，于是"加数据、加层数"这条路第一次被彻底打通。而 √d_k 缩放、残差、LayerNorm 各自对症 softmax 饱和与深层训练不稳（全是第二站的遗产）。

**猫的角色**：LSTM 要把"猫"的信息一步步传到"它"，中间经过 4 个词、步步衰减；Transformer 里"它"一眼看向全句，距离不复存在。

**为什么出现在 2017 而不是 1997？** 它放弃了卷积的局部性、RNN 的顺序性等全部结构先验，意味着一切规律都要靠数据和算力硬吃——这正是 2017 年才具备的条件。原理不难，难的是"敢放弃先验"的底气，而底气是 GPU 和互联网语料给的。

### 3.5 两个儿子：BERT 与 GPT

Transformer 给出了架构，但标注数据依然贵。下一个问题：**能不能用无标注文本先训出通用语言能力，再低成本适配具体任务？** 两篇论文给出两个方向。

**BERT（Devlin et al., 2018）**——理解路线，确立"预训练 + 微调"范式。

- 问题：每个 NLP 任务都从随机初始化+少量标注开始训练，浪费又低效。无标注文本遍地都是，怎么利用？
- 原理：在海量无标注文本上自监督预训练双向编码器，两个预训练任务。**掩码语言模型（MLM）**：随机盖住 15% 的词让模型填空——为防训练和推理不一致，被选中的词 80% 换成 [MASK]、10% 换成随机词、10% 保持不变。**下一句预测（NSP）**：判断两句是否相邻。双向注意力让每个词能看到左右全部上下文。之后接一个任务头微调，横扫 11 项 NLP 任务。
- 为什么对症："填空"是一个不需要人工标注、却逼迫模型理解全句的任务——标签免费，于是预训练规模可以拉到互联网级别；双向上下文则让它在"理解类"任务上信息最全。
- 猫的例子：给"今天天气真[MASK]，我们去遛猫吧"填出"好"。要填对这个空，模型得同时看左边的"天气"和右边的"遛猫"——这正是双向的意义。学会填空后，头顶接个分类层、几千条标注微调，就能做情感分析、问答。

**GPT-1/2/3（Radford 2018–2019; Brown et al., 2020）**——生成路线，长成今天的大语言模型。

- 问题：同 BERT，但选另一个自监督任务：只做"预测下一个词"，即建模 P(x) = Π P(xₜ|x_{<t})。
- 原理：只用解码器 + 掩码自注意力（每个词只能看左边）。GPT-3 把参数堆到 1750 亿（96 层、隐维 12288），发现模型**涌现**出 few-shot 能力：不给梯度更新，只在提示里给几个示例（in-context learning），模型把示例当作"上文模式"继续外推。
- 为什么对症："预测下一个词"看似简单，实则是**最通用的任务格式**——任何任务（翻译、问答、写作）都可以写成"给定上文、续写下文"的形式，于是预训练目标和各种下游应用零缝隙对齐；而规模足够大之后，这个简单目标逼出了对世界的建模能力——想预测好下一个词，就得懂语法、懂事实、懂推理。
- 猫的例子：提示写"英文: cat → 法文: chat；英文: dog → 法文: chien；英文: cheese →"，模型直接续写"fromage"。它没专门学过翻译，全靠从预训练语料中"悟"出的模式。

BERT 擅长理解，GPT 擅长生成。历史选择了后者——自回归目标与"生成一切"的野心天然契合。

## 第四站：画出猫——生成模型的三次浪潮

前三站让机器能"识别"猫，这一站要"创造"不存在的猫。**本站的中心问题**：怎么让模型学会数据的概率分布本身，并从中采样出新样本？三波浪潮，每一波都是对上一波破绽的对症回应——记住这条问题链：VAE 模糊 → GAN 不稳 → 扩散来收场。

### 4.1 第一波：VAE——把生成变成数学（Kingma & Welling, 2013）

**问题**：要生成新图像，就得学出数据的分布 p(x) 并从中采样。但引入隐变量 z 之后，p(x) = ∫p(x|z)p(z)dz 这个积分算不出来（z 是连续变量，要对无穷多个取值求和），标准的贝叶斯路线（EM 那套）在深度模型面前走不通。

**原理**：编码器不输出一个向量，而是输出隐变量的**分布** q_φ(z|x) = N(μ, σ²)。训练目标是最大化证据下界（ELBO）：

```
L = E_q[log p_θ(x|z)]  −  KL(q_φ(z|x) ‖ N(0, I))
    └ 重建项：解码得像 ┘   └ 正则项：隐分布别偏离标准正态 ┘
```

采样操作 z ~ N(μ, σ²) 不可微，用**重参数化**绕过：z = μ + σ ⊙ ε，ε ~ N(0, I)。代个数：编码器输出 μ=1.5、σ=0.4，从标准正态采到 ε=−0.8，则 z = 1.5 + 0.4×(−0.8) = 1.18。随机性全在 ε 里（挪到输入侧），μ、σ 是普通数值，梯度畅通。

**为什么对症**：两招各解一个死结——ELBO 把"算不出的积分"换成"可优化的下界"，不可解问题变成了可训练目标；重参数化把"采样"这个随机操作挪出梯度路径，让随机过程也能反向传播。而正则项把隐空间压成连续规整的形状——想象所有"猫的配方"都被强制誊写到统一规格的卡片上、整齐码放，于是"采样新数据"变成"随手抽一张卡片再解码"；若不做正则（σ→0），配方散落各处、中间全是空洞，抽到空洞就解码出垃圾。

**猫的角色**：可以插值：从"微笑的猫"配方卡滑向"严肃的猫"，解码出一系列渐变图像；随机采一个 ε，就"造"出一只不存在的猫。代价是重建项用逐像素误差——"每个像素平均而言差不多"惩罚不了模糊（把 10 种可能的猫脸平均成一张，像素误差反而最小，但画面糊了），生成图像偏糊。这个代价就是下一波的理由。

### 4.2 第二波：GAN——造假者与验钞员（Goodfellow et al., 2014）

**问题**：VAE 的模糊根源在损失函数——"逐像素误差"这种手写的、固定的相似度度量，根本表达不了"这张图看起来像不像真的"。而显式建模密度 p(x) 这条路本身又难走。能不能**不建模密度，也不手写损失**，让"像不像"由一个可学习的东西来定义？

**原理**：极小极大博弈：

```
min_G max_D  E_{x~数据}[log D(x)] + E_{z~噪声}[log(1 − D(G(z)))]
```

判别器 D 最大化"辨真伪"能力，生成器 G 最小化 D 的判别能力。代个数看均衡点：当生成的猫已经真假难辨时，D 对任何输入都只能输出 0.5（纯瞎猜），此时 log 0.5 + log(1−0.5) = −2log2，谁都改进不了——纳什均衡。理论上：固定 G 时最优 D*(x) = p_data(x)/(p_data(x)+p_g(x))，此时 G 的目标等价于最小化 p_data 与 p_g 的 JS 散度。

**为什么对症**：损失函数不再是人写的，而是**另一个网络**——D 有多毒辣，G 得到的监督就有多精准。"像不像"这个模糊概念被替换成了一个可以训练、随对手进化的信号源，所以生成质量（尤其清晰度）碾压 VAE，统治 2014–2019。

**猫的角色**：伪钞制造者（G）和验钞员（D）军备竞赛：第一回合 G 画的猫三只眼睛，D 一眼识破；G 学会画两只眼睛，D 改看胡须；G 补上胡须，D 改看毛发纹理……直到猫片逼真到验钞员只能瞎猜——StyleGAN 的生成人脸就是这么来的。代价：训练不稳（JS 散度在两个分布几乎不重叠时是常数，梯度消失，G 收不到任何改进信号）、模式崩溃（G 发现某一种猫总能骗过 D，就只会画这一种）——两人博弈天然难收敛，这两点正是下一波浪潮要解决的问题。

### 4.3 第三波：扩散模型——学会"倒放"（Ho et al., 2020，DDPM）

**问题**：GAN 的病根在于训练目标是"两人博弈"——没有固定靶，优化过程随时可能被对方带崩。有没有一种生成方法，训练过程像普通监督学习一样**稳定、目标固定**，质量还不输甚至超过 GAN？

**原理**：

- **前向加噪**（固定，无参数）：T=1000 步逐步加高斯噪声 q(xₜ|x_{t-1}) = N(√(1−βₜ)·x_{t-1}, βₜI)，β 从 0.0001 缓增到 0.02——每张猫片被沙尘暴一点一点掩埋，1000 步后只剩纯噪点。利用高斯的可叠加性可一步跳到任意时刻：xₜ = √ᾱₜ·x₀ + √(1−ᾱₜ)·ε，其中 ᾱₜ = Π(1−βᵢ)。
- **反向去噪**（要学的）：训练 U-Net ε_θ(xₜ, t) 预测当时加入的噪声，损失简单到不可思议：

```
L = ‖ ε − ε_θ(xₜ, t) ‖²
```

代个数：随机抽一张猫片、随机抽第 613 步，按公式一步算出 x₆₁₃（半张猫半张沙），网络看着 x₆₁₃ 和 t=613，猜"这张图里的沙是哪一把"（噪声 ε），猜错就梯度下降。每张训练图免费产出 1000 个这样的监督样本。

- **生成**：从纯噪声 x_T ~ N(0, I) 出发，逐步计算 p_θ(x_{t-1}|xₜ)（均值由预测的噪声推出），每步只擦掉薄薄一层沙，擦 1000 次，迭代得到 x₀。

**为什么对症**：它把"一步生成一张图"这个超高难度任务，沿时间轴拆成 1000 个"稍微去一点噪"的小回归问题——每个小问题的输入输出都是现成的（加噪过程免费制造训练对），训练就是纯监督学习，**没有对手、没有博弈**，自然稳如直线；而"每步只改一点点"也让模型能精雕细琢，生成质量超越 GAN，成为当今图像/视频生成的主流。

**猫的角色**：模型看过无数张猫片"被沙尘暴逐渐掩埋"的全过程，于是学会倒放：给一团噪点，一步步擦，擦着擦着浮现出一只清晰的猫。

### 4.4 实用化：Latent Diffusion / Stable Diffusion（Rombach et al., 2022）

**问题**：DDPM 在像素空间逐步去噪，一张 512×512 的图有 78 万个像素，要迭代几百步——算力需求让文生图只能待在实验室，消费级 GPU 跑不动。另外，怎么用"文字"控制生成内容？

**原理**：

1. **感知压缩**：先用 VAE 把 512×512×3 的图像压成 64×64×4 的隐表示——数据量小了 48 倍，人眼几乎看不出损失，但扩散的计算量骤降；
2. **隐空间扩散**：DDPM 的那套加噪/去噪全部在隐空间进行；
3. **条件注入**：文本经 CLIP 文本编码器（见 4.5）变成向量序列，通过**交叉注意力**（U-Net 的 Q 来自图像，K、V 来自文本）注入每一步去噪；推理时用 classifier-free guidance 放大文本的引导强度。

**为什么对症**：两个洞察——像素空间里大部分计算浪费在"人眼无感的细节"上（相邻像素差一点值，你根本看不出），先压缩到语义隐空间再扩散，等于只给"内容"建模、不给"冗余像素"建模，算力需求降一个数量级；交叉注意力则对症"文字怎么指挥图像"：每步去噪时，图像都"回头查询"一遍文本向量（注意，这就是 Bahdanau 那套机制第三次出现），文字指导由此嵌入生成的每一步。

**猫的角色**：输入"一只穿宇航服的猫，赛博朋克风格"。每步去噪时，"猫"相关的隐空间区域去查询文本里的"cat"、"宇航服"区域去查询"astronaut"——文字像指挥家，几十步后隐空间图像成形，解码出高清图。注意：VAE（4.1）和 CLIP 都回来了——第四站用上了前面所有积累。

### 4.5 补一块：CLIP（Radford et al., 2021）

- 问题：传统图像分类每加一个新类别就要重新收集标注、重新训练；而文生图、多模态应用需要一座桥——让"文字"和"图像"能在同一个空间里比较。
- 原理：对比学习。一个 batch 取 N 对（图, 文），图像编码器和文本编码器各自输出向量，最大化 N 个配对的余弦相似度、最小化 N²−N 个错配的相似度（InfoNCE 损失，带温度系数 τ）。代个数：batch 里 4 对图文，构成 4×4 相似度矩阵——对角线（猫图×"a photo of a cat"）该最大，其余 12 个错配（猫图×"a photo of a dog"）该最小。训练就是在把对角线拉高、非对角线压低。4 亿对网络图文训练。
- 为什么对症：把图和文压进**同一个向量空间**之后，"分类"变成了"检索"——比较图片向量和候选描述文本向量的距离即可，类别从"训练时固定的输出节点"变成"推理时随便写的句子"，零样本泛化由此而来（追平有监督 ResNet）；而"文字和图像可比较"正是文生图里"文字指导图像"的前提。
- 猫的例子：从未标注过"金毛犬"训练集，只需把图片与候选文本"a photo of a golden retriever"分别编码，谁的向量最近就判给谁。

## 第五站：抓老鼠——强化学习，从感知到决策

会看、会说、会画，还差最后一样：**行动**。**本站的中心问题**：监督学习需要标准答案，但"抓老鼠"没有标准动作序列——只有偶尔到来的奖惩。怎么从稀疏的反馈信号里学会一连串动作？RL 的框架：智能体在环境中试错，按奖励信号调整策略，目标是最大化长期回报 E[Σ γᵗ rₜ]。

### 5.1 算法基石：Q-Learning（Watkins, 1989/1992）

**问题**：环境是黑盒——不知道撞墙的概率、老鼠会往哪跑（转移概率未知），经典动态规划需要环境模型，直接用不了。能不能**不需要模型**，直接从交互经验里学出最优策略？

**原理**：学 Q(s, a) = 状态 s 下做动作 a 的长期回报。时序差分（TD）更新：

```
Q(s,a) ← Q(s,a) + α[ r + γ·max_{a'} Q(s',a') − Q(s,a) ]
                     └────── TD 目标 ──────┘  └ 当前估计 ┘
```

代个数走一遍：机器猫在迷宫门口，Q(门口, 右) 目前是 0。它往右走了一步，拿到奖励 r = −0.1（白走一步小扣分），落进的新格子里最好的 Q 值是 0.5。取学习率 α=0.1、折扣 γ=0.9：

```
Q(门口, 右) ← 0 + 0.1 × [ −0.1 + 0.9×0.5 − 0 ] = 0.035
```

"往右走"第一次有了正的身价。再看奖励怎么倒流：抓到老鼠那一格 Q 先涨到 1.0，它前一格的目标值变成 0.9×1.0=0.9，前前两格变成 0.9×0.9=0.81……**奖励像水一样沿动作链逆流回起点**，整条路径上的格子身价依次抬升。它是 off-policy 的：更新时假设下一步走最优动作，与实际探索用的行为策略解耦。论文证明了收敛性。

**为什么对症**：自举（bootstrap）是解"没有环境模型"的关键——不需要知道世界怎么运转，用**自己的估计修正自己的估计**，奖励信号就能沿动作链倒流回起点。off-policy 则把"探索"和"利用"解耦，可以边乱走边学最优。

**猫的角色**：Q 值全 0 起步，乱走撞墙扣分、抓到老鼠得分。几万次尝试后，"离老鼠更近"的格子 Q 值越来越高，沿 Q 值最大的方向走就是最短路径——没人告诉它地图，它把地图学进了 Q 表里。

### 5.2 与深度学习会师：DQN（Mnih et al., 2013/2015）

**问题**：Q 表要枚举所有状态——Atari 游戏画面是 84×84 像素，状态数比宇宙原子还多，表根本存不下，得用神经网络近似 Q。但直接换上有两个致命不稳：连续采样的数据**时序相关**（连着的 100 帧几乎一模一样，违反梯度法的 i.i.d. 假设）；TD 目标里包含网络自己的输出——**目标跟着参数一起动**，回归在追自己的尾巴，容易发散。

**原理**：用 CNN 直接读画面像素学 Q 函数，外加两个稳定器，一个对一个病因：

1. **经验回放**：把 (s, a, r, s') 存进一个能装 100 万条经验的回放缓冲区，训练时随机抽 mini-batch——今天的样本和上周的样本混在一起抽，时序相关性被打乱，样本近似 i.i.d.；
2. **目标网络**：另存一份冻结的 Q⁻，TD 目标 r + γ·max Q⁻(s') 用它计算，每隔 C 步（比如 1 万步）才把在线网络的参数拷过去——靶子先钉死，打一阵子再挪，回归问题变稳。

策略上用 ε-greedy：以 ε 概率随机探索，否则选 Q 最大的动作。结果：49 款游戏达到人类水平——深度学习与强化学习的第一次会师。

**为什么对症**：注意两个稳定器都不是锦上添花，而是精确对症两个崩溃源——回放治"数据相关"，目标网络治"目标移动"。这也是深度 RL 工程的通用教训：先看失败模式，再对症下药。

**猫的角色**：只看像素和得分，DQN 在打砖块里自己发现"把球打到砖墙后面反弹"的最优策略——没人教过它，它甚至发现了人类玩家没总结过的技巧。

### 5.3 破圈时刻：AlphaGo（Silver et al., 2016）

**问题**：围棋每步约有 250 个合法落点、平均对局 150 手，搜索空间约 250¹⁵⁰ ≈ 10³⁶⁰，暴力搜索无望（深蓝那套在国际象棋上可行，在围棋上是天文数字）；人类棋谱可以模仿，但模仿人类最多达到人类水平——怎么超越？

**原理**：三件套。

1. **策略网络 p(a|s)**：先模仿 3000 万步人类棋谱做监督学习（SL），再自我对弈做策略梯度强化（RL）——给"直觉选点"，把每步要细看的候选从 250 个砍到几个；
2. **价值网络 v(s)**：评估局面胜率——不必搜到终局，下到一半就能打分"这局面白棋胜率 63%"，砍掉搜索的深度；
3. **蒙特卡洛树搜索（MCTS）**：每步用 PUCT 公式选点（综合价值评估与策略网络的先验概率），模拟推演上千次后选访问次数最多的落子——给"细算"。

后续 AlphaZero 更彻底：去掉人类棋谱，从零自学，三天碾压 AlphaGo。

**为什么对症**：两个网络分别砍掉搜索的**宽度**和**深度**——直觉（策略网络）决定"重点想哪几步"，判断（价值网络）决定"想多远就够"，MCTS 把两者缝起来：10³⁶⁰ 的空间，实际每步只认真推演几百条变化。而"自我对弈 + 胜负奖励"提供了一个不依赖人类经验的、无限供应的训练信号——超越人类由此成为可能。

**猫的角色**：对李世石第二局第 37 手那步"肩冲"，职业棋手初看以为是失误——自我对弈的奖励信号让它敢下人类经验里不存在的棋。RL 突破人类经验边界的标志性瞬间。

### 5.4 工程收敛点：PPO（Schulman et al., 2017）

**问题**：策略梯度方法有个实践灾难：步长没控制好，一次更新就可能把策略改崩（好比调收音机，一把拧过头，台就没了，而且 RL 里没有"撤销"——策略崩了之后采到的数据也是崩的，恶性循环）。理论上严谨的 TRPO 实现复杂到没人愿意用。需要一个**既稳又简单**的算法。

**原理**：用重要性采样比 rₜ(θ) = π_θ(a|s)/π_old(a|s)，并把目标函数截断：

```
L^CLIP = E[ min( rₜ·Âₜ,  clip(rₜ, 1−ε, 1+ε)·Âₜ ) ]
```

Âₜ 是优势函数（这个动作比平均水平好多少），ε=0.2。代个数：某动作新旧概率比 rₜ = 1.5（新策略做这个动作的概率涨了 50%），优势 Âₜ = +2（是个好动作）。没 clip 时目标贡献 1.5×2 = 3.0，越涨越奖励；clip 之后贡献被截在 1.2×2 = 2.4——概率比超过 1.2 之后梯度归零，**再诱人的方向也只许走 20%**。

**为什么对症**：TRPO 用复杂的二阶优化来约束步长，PPO 发现**在目标函数里加一行 clip 就够了**——单次更新天然不会走太远。用 10% 的复杂度拿到 90% 的效果，因此成为 RL 事实上的默认算法——包括后来训练 ChatGPT 的那一次。

**猫的角色**：像调收音机每次只许拧一小格，信号好就继续、差就回退，绝不一把拧飞。稳定，因此可以跑千万步不崩。

### 5.5 终点即起点：InstructGPT / RLHF（Ouyang et al., 2022）

**问题**：GPT-3 会"续写文本"但不会"答人所问"——问它"怎么向 6 岁小孩解释猫为什么会呼噜"，它可能续一段跑题的网页文本。问题在于"有用、诚实、无害"这种人类偏好**没法写成可微的损失函数**，监督学习和 RL 都接不上。

**原理**：三步走。

1. **SFT**：人工写示范回答，对预训练模型做监督微调；
2. **训练奖励模型（RM）**：对同一 prompt 采样多个回答，人工**排序**——比如 4 个回答排出 A > D > B > C，产生 6 对两两比较；用 pairwise 损失 L = −log σ(r_好 − r_差) 训一个打分模型，把人类偏好压缩成标量奖励；
3. **PPO 优化**：以 RM 打分为奖励、用 PPO 更新语言模型，同时加 KL 惩罚项防止模型偏离 SFT 模型太远（否则它会找到 RM 的作弊漏洞——比如学会输出某种 RM 偏爱但人类讨厌的怪格式）。

**为什么对症**：三步各解一个死结——"偏好不可微"用 RM 解（把偏好蒸馏成一个能打分的网络，于是 PPO 有奖励可用）；"绝对打分标准飘忽"用成对排序解（"哪个更好"比"打几分"标注稳定得多，见 7.2）；"模型会讨好 RM 而跑偏"用 KL 惩罚解。结果：1.3B 的 InstructGPT 在人类偏好上反超 175B 的原始 GPT-3——参数小了 130 倍，人却更喜欢它。**对齐比规模更值钱**。

**猫的角色**：RLHF 后的模型学会耐心贴题地给 6 岁小孩作答——"猫呼噜就像你在妈妈怀里时会哼歌一样"。标注员给"有用、诚实、无害"的回答打了高分，人类的偏好被刻进了模型。注意：这一步把第五站（PPO）和第三站（GPT）焊在了一起——ChatGPT 就是这么来的。

## 第六站：大模型时代——规模、能力、效率

**本站的中心问题**：Transformer + 预训练范式已经成立，剩下三个现实问题：砸大钱之前怎么知道规模越大越好（6.1）？已有的大模型怎么把能力和知识用起来（6.2）？训练和推理怎么降本（6.3）？

### 6.1 规模即科学：Scaling Laws（Kaplan et al., 2020）

**问题**：GPT 路线暗示"越大越强"，但训练一次大模型要上亿美元——拍脑袋决策没人敢签字。规模和能力之间到底是什么定量关系？能不能**先算出来再砸钱**？

**原理**：固定其他变量，单独扫一个变量，发现语言模型 loss 与参数量 N、数据量 D、算力 C 之间呈平滑幂律，log-log 图上都是直线：

```
L(N) ≈ (N_c/N)^α_N        L(D) ≈ (D_c/D)^α_D        L(C) ≈ (C_c/C)^α_C
```

代个数：α_N 约为 0.076——参数量扩大 10 倍，loss 大约乘以 10^(−0.076) ≈ 0.84。看着不多？连续外推 3 个数量级（千倍参数），loss 降约 40%，而且直线不拐弯——这就是"还能涨"的证据。由此可推算：给定算力预算，模型和数据该怎么分配才最优（后续 Chinchilla 论文修正为：数据量应与参数量等比增长，多数大模型其实"训得不够"）。

**为什么对症**：幂律的价值在于**平滑可外推**——能力不是玄学跃迁，而是一条可以用小规模实验拟合、再向大规模外推的曲线。于是"要不要砸钱训 100 倍大的模型"从信仰问题变成了工程计算问题。大力出奇迹从此从信仰变成工程。

**猫的角色**：用 1000 万美元的小实验测出幂律曲线，就能外推"投 1 亿美元训 100 倍大的模型，loss 降到多少"——GPT-4 正是这样被"算"出来的。

### 6.2 能力的免费午餐：思维链与 RAG

**Chain-of-Thought（Wei et al., 2022）**

- 问题：大模型直接输出答案，数学/逻辑题频频翻车——不是不会算，而是"一步登天"：从问题到答案的映射太复杂，一步映射不过来。又不许改模型、不许重训，怎么办？
- 原理：在 few-shot 示例里加入"一步步推理再作答"的过程。自回归模型的每一步生成都可以利用已生成的上文——显式写出中间步骤，等于把一步高难度映射拆成一串低难度映射，同时给后续生成提供了"工作记忆"。只在模型足够大（约百亿以上）时才涌现。这条线索后来长成 o1/R1 类推理模型。
- 为什么对症：不改模型、不加数据，只是**改变了"使用模型"的方式**——让模型把思考过程也生成出来。对自回归架构来说，生成的中间步骤就是免费的外置记忆和计算草稿，难度被摊到时间步上。成本几乎为零，数学/逻辑准确率大增。后续扩展 self-consistency：采样多条推理路径，多数投票取答案。
- 猫的例子："食堂有 23 个苹果，用掉 20 个，又买 6 个，剩几个？"直接答，模型容易蹦出"5"；让它写"23−20=3，3+6=9，剩 9 个"，就对了——心算三位数乘法你也会错，给你纸笔就不会，CoT 就是给模型发纸笔。

**RAG（Lewis et al., 2020）**

- 问题：模型的知识冻结在训练截止那天，新知识进不来；问它不知道的事，它不会说"不知道"，而是**幻觉**——一本正经地编。重训模型更新知识又太贵。
- 原理：检索 + 生成两段式。检索器（如 DPR，双塔结构）把问题和文档分别编码成向量，用内积召回最相关的 k 篇文档；生成器把"问题 + 检索到的文档"一起作为输入，逐词生成回答：

```
p(y|x) ≈ Σ_z p_η(z|x) · p_θ(y|x, z)
```

- 为什么对症：把"记忆"从模型参数里**搬到外部向量库**——背书变开卷考。知识更新只需换库，不用重训；回答有出处可查，幻觉空间被压缩。这是幻觉与知识过时问题的主流工程解。
- 猫的例子：问"我们公司今年的年假政策"，纯模型只能瞎编；RAG 先从 10 万份文档里翻出《2026 考勤制度》第 3.2 条贴进提示，模型开卷作答并附引用。

### 6.3 效率的三驾马车

大模型越大越贵，三篇论文各拆一面墙——各自针对"贵"的一种形态。

**LoRA（Hu et al., 2021）——微调太贵**

- 问题：70 亿参数的模型，全量微调要存梯度和优化器状态（Adam 要额外存两份动量），显存需求是模型本身的好几倍，上百 GB，普通团队玩不起。
- 原理：预训练权重 W₀ ∈ R^{d×k} 不动，增量 ΔW 用低秩分解表示：

```
W = W₀ + ΔW = W₀ + B·A,   B ∈ R^{d×r}, A ∈ R^{r×k},  r ≪ min(d, k)
```

代个数：一层 4096×4096 的权重，全量 ΔW 有 1670 万参数；取 r=8，则 A 和 B 合计 2×4096×8 ≈ 6.5 万——只有原来的 0.4%。

- 为什么对症：一个经验观察——大模型已经学得很全，微调所需的权重变化本来就是**低内在秩**的（只是"拨一拨"，不是"重学一遍"）。既然如此，只为这个小增量分配参数就够了：可训练参数降到 0.1%–1%，效果接近全量微调；推理时把补丁合并回原权重，零额外延迟。
- 例子：LoRA 只练约 800 万参数，消费级显卡几小时教会模型医疗问答风格。

**MoE / Switch Transformer（Fedus et al., 2021）——推理太贵**

- 问题：Scaling Law 说参数越多越好，但稠密模型参数翻倍、每个 token 的计算量也翻倍——能力和成本锁死在一起。能不能**解耦**？
- 原理：把 Transformer 的前馈层（FFN）复制成 N 个"专家"，每层加一个路由网络：对输入 token 算 N 个专家的 softmax 分数，只把它送进 top-1（或 top-k）专家，输出按门控分数加权：

```
y = Σ_{i ∈ top-k} G(x)ᵢ · Eᵢ(x)
```

代个数：64 个专家、每个 token 只走 top-2——模型总参数是稠密版的几十倍，但每个 token 只动用 2/64 ≈ 3% 的专家。为防止所有 token 挤向少数专家，加负载均衡辅助损失；设专家容量上限，超出的 token 走残差旁路。

- 为什么对症：总参数量（知识容量）和单次计算量（推理成本）被拆开——参数量扩到 1.6 万亿，但每个 token 只激活一小撮专家，计算量不变，训练速度比同算力稠密模型快数倍。GPT-4、DeepSeek 等大模型普遍采用此结构。
- 例子：大医院分诊——病人按症状只去一个科室，不必所有医生会诊。总"医生数"（参数）可以极多，每次看病（计算）成本不变。

**FlashAttention（Dao et al., 2022）——显存带宽太贵**

- 问题：注意力理论上的 FLOPs 并不高，实际却慢——profile 后发现瓶颈不在算，而在**搬**：N×N 的 QKᵀ 矩阵要在 HBM（显存）与 SRAM（片上缓存）之间来回读写。代个数：序列长 8K 时 N×N 矩阵有 6400 万个元素，写显存再读回；而 GPU 从 HBM 读数据比做乘加慢一个数量级以上——大部分时间在等搬运。序列一长，显存先爆（O(N²)）。
- 原理：分块（tiling）：把 Q、K、V 切成小块载入 SRAM，在片上完成该块的注意力计算；用**在线 softmax**（维护运行中的最大值与归一化和）保证跨块结果正确；反向传播时不存中间矩阵，需要时现场重算。
- 为什么对症：三招全部针对"搬运"而非"计算"——分块让中间结果不出 SRAM，N×N 矩阵从不落显存（占用降到 O(N)）；在线 softmax 解决"分块后 softmax 需要全局归一化"的矛盾（每来一块就更新一次运行最大值和归一化和，扫完即得全局正确结果）；重计算用便宜的算力换金贵的显存带宽。结果：提速 2–4 倍且结果**精确**（不是近似），长上下文由此可行。
- 例子：原来算注意力像把厚书来回从书架搬到书桌；现在把书撕成小册子一次处理一叠，书桌放不下中间结果就现场重算——总搬运量大减。

## 第七站：工程借鉴——这些论文里的优秀实践可以直接拿走

经典论文的价值不只在理论，更在于它们沉淀了一批**反复被验证的工程范式**。以下六组实践，几乎可以在任何机器学习项目里直接使用。每组都按"它本来解决什么问题 → 怎么迁移到你的问题"来讲。

### 7.1 训练稳定性工具箱：深网络不崩的套路

今天训练任何深网络，起手就是一套标准动作，每一招都有出处：

- **加直通车道**（ResNet）：本来解决"网络加深反而更差"的退化问题。迁移：出现这个现象时，先怀疑优化失败而非过拟合，给梯度留一条恒等通路。这个思想已泛化到一切"残差化"设计：Transformer 的子层、扩散模型的 U-Net 跳跃连接。
- **逐层校准分布**（BN/LayerNorm）：本来解决"前层一变、后层输入分布就漂移"的内部协变量偏移。类比工程里的"每个模块约定统一的接口规格"——上游怎么改，下游拿到的输入分布都是稳的。
- **限制单步更新幅度**（PPO、RLHF 的 KL 惩罚）：本来解决"策略一次更新走太远就崩"。新旧策略差异超界就截断；新模型偏离参考模型太远就扣分。"小步快跑、绝不一把拧飞"是迭代式优化的通用安全绳——迁移到工程上，就是灰度发布与金丝雀部署。
- **梯度裁剪 + Adam 默认值**：β₁=0.9、β₂=0.999 这两个数字经受了十年检验，没有理由改。

### 7.2 数据即护城河：好数据怎么造出来

- **数据增强是免费的数据**（AlexNet）：本来解决"训练集不够大"。裁剪、翻转、颜色抖动把训练集变相扩大数千倍。今天每条模态都有自己的增强：文本的回译与改写、语音的变速加噪。
- **数据飞轮**（SAM 的 Data Engine）：本来解决"分割掩码标注太贵"。模型辅助标注 → 人工只修不标 → 重训更强的模型 → 标注更快。三轮滚动，从 0 攒出 10 亿掩码。**先用弱模型把人从"生产数据"变成"审核数据"**，标注效率提升一个数量级——这是任何标注项目都该抄的作业。
- **排序优于打分**（RLHF）：本来解决"人类偏好标注标准飘忽"。让人给回答打 1–10 分，一致性差；改成"两个回答哪个好"的成对排序，标注又快又稳，再用 pairwise 损失 `-log σ(r好 − r差)` 训出连续的奖励模型。**把绝对评价问题转化为相对比较问题**，是收集人类偏好的黄金法则。
- **小模型 + 好数据 > 大模型**（InstructGPT）：1.3B 对齐后的模型在人类偏好上反超 175B 未对齐模型。预算有限时，先投数据与对齐，再谈堆参数。

### 7.3 近似与分解：把大问题切小到算得动

三篇论文，三个"降本"的通用思想：

- **低秩假设**（LoRA）：本来解决"微调太贵"。"微调所需的变化是低秩的"——全量矩阵不动，只学两个小矩阵的乘积。推而广之：当全量更新太贵时，先问"变化是否真的需要满秩表达"。
- **稀疏激活**（MoE）：本来解决"参数规模与推理成本锁死"。总容量与单次成本解耦——参数可以万亿，每次只激活一小撮。工程等价物：冷热分离、按需加载。
- **先压缩再计算**（Stable Diffusion 的 VAE 隐空间、RAG 的向量库）：本来解决"像素空间扩散算不动"和"全部知识塞不进参数"。不在原始高维空间硬算，先压到语义稠密的低维空间再处理。感知压缩丢掉的是人不在乎的信息，省下的是一个数量级的算力。

### 7.4 系统思维：瓶颈常在搬运，不在计算

- **IO 感知**（FlashAttention）：本来解决"注意力 FLOPs 不高却很慢"。优化前先 profile——N×N 矩阵在显存与缓存间的来回搬运才是真瓶颈。**先分清你的程序是 compute-bound 还是 memory-bound**，再决定优化方向；对后者，分块（tiling）与融合（fusion）是标准解法。
- **以算换存**（FlashAttention 的重计算、反向传播的 checkpointing）：本来解决"中间结果显存放不下"。不存，需要时现场重算。算力相对便宜、显存带宽金贵，这笔交换几乎总是划算。
- **在线算法**（在线 softmax）：本来解决"softmax 需要全局统计、但数据一趟扫不完"。维护运行中的统计量（最大值、归一化和）流式处理。MapReduce、流式聚合里是同一思想。

### 7.5 实验方法论：怎么把"感觉"变成"证据"

- **先定义问题，再设计方案**（ResNet）：作者先用实验证明"56 层训练误差 > 20 层"，把矛头从过拟合（测试误差高）精确指向优化失败（训练误差就高），残差连接是对症的解法。**区分训练误差与测试误差，是最基本的诊断分流**。
- **控制变量 + 消融**（VGG）：固定 3×3 卷积核，一次只加深一层，干净地证明"深度本身有效"。一次只改一个变量，结论才可归因。
- **小实验外推大决策**（Scaling Laws）：在拟合出的幂律曲线上，千万美元级的训练决策可以用百万美元级的实验预测。任何昂贵的系统都值得先问：**它的 scaling 曲线长什么样？**
- **拥抱简单基线**（Adam、PPO）：PPO 不是理论上最优的算法，但"90% 的性能 + 10% 的实现难度"让它统治了工业界。工程选型时，可调试性往往比理论优雅值钱。

### 7.6 设计哲学：两条反复应验的规律

- **先验是脚手架，不是承重墙**（CNN → ViT）：数据少时靠结构先验（局部性、平移性）起步；数据够了，通用架构 + 规模反而更强。设计系统时值得标注：哪些假设是"当前数据量下的权宜之计"，时机到了就该拆掉。
- **创新常常是旧积木的新组合**（Stable Diffusion = VAE + DDPM + CLIP；ChatGPT = Transformer + Scaling + PPO + 排序标注）：突破性产品未必含突破性论文，把成熟组件按新方式组合，本身就是最重要的工程能力。

### 一张对照表：遇到问题，借鉴谁

| 你遇到的问题 | 借鉴哪篇 | 怎么做 |
|---|---|---|
| 网络加深反而更差 | ResNet | 加残差连接，区分退化与过拟合 |
| 训练发散、loss 震荡 | BN、PPO | 层输入标准化；限制单步更新幅度 |
| 标注数据太贵 | SAM、RLHF | 模型预标 + 人工审核的飞轮；用成对排序代替绝对打分 |

## 收尾：整张拼图拼好了

回看我们的目标，那只猫的旅程串起了全部 40 篇论文。现在再看这张表，注意每一行都是"问题 → 解题人"的关系：

| 目标 | 要解决的核心问题 | 关键论文 |
|---|---|---|
| 机器能算吗 | 神经元如何形式化、权重如何自动学 | McCulloch-Pitts → 感知机 → 反向传播 |
| 看懂猫 | 特征人设计不全 → 端到端学特征 | LeNet → AlexNet → ResNet → ViT/SAM |
| 谈论猫 | 符号无语义、长距离传不动 → 向量 + 注意力 | word2vec → LSTM → 注意力 → Transformer → BERT/GPT |
| 画出猫 | 分布怎么学、生成怎么稳 | VAE → GAN → DDPM → Stable Diffusion |
| 抓老鼠 | 没有标准答案、只有奖惩 → 从反馈中学 | Q-learning → DQN → AlphaGo → PPO → RLHF |
| 做大做强 | 规模怎么算、成本怎么降 | Scaling Laws → CoT/RAG → LoRA/MoE/FlashAttention |
| 工程怎么做 | 实践沉淀 | 稳定性工具箱、数据飞轮、低秩/稀疏/压缩、IO 感知、实验方法论（见第七站） |

几条值得记住的规律：

1. **后一篇论文总在前一篇的破绽处诞生。** 这就是全文的暗线，把这条问题链完整走一遍：感知机死于 XOR → 反向传播解开多层训练 → 网络加深又遇退化 → ResNet 解开深度 → Seq2Seq 死于定长向量瓶颈 → 注意力解开瓶颈 → RNN 死于串行不可并行 → Transformer 扔掉循环 → 预训练模型不会"答人所问" → RLHF 完成对齐；另一条线上：VAE 死于模糊 → GAN 用可学习损失解开 → GAN 死于训练不稳 → 扩散模型用"拆成一千步小回归"收场。**每个原理都是对症药，每副药又留下新的副作用。**
2. **算力是隐形的作者。** Transformer 放弃结构先验、ViT 抛弃卷积先验、Scaling Law 信奉规模——它们的胜利本质上是数据与算力的胜利。先验让位于通用性，是七十年里最反复出现的主旋律。
3. **主线在收拢。** 2012 年之前各任务各有专门方法；2017 年之后，Transformer 一个架构统一了视觉、语言、语音、多模态；2022 年之后，"预训练 + 对齐"一个范式统一了几乎所有任务。

**按问题速查**：

- 模型为什么训得动？→ 反向传播、ResNet、Dropout/BN、Adam
- 为什么 Transformer 统一一切？→ LSTM、Attention、Transformer、ViT、CLIP
- ChatGPT 怎么来的？→ Transformer、GPT-3、Scaling Law、PPO、RLHF
- 大模型怎么降本增效？→ LoRA、MoE、FlashAttention、RAG
