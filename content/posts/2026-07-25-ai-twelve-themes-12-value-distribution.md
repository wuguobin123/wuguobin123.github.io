## 三层结构的常见误解

很多人把 AI 产业画成这样的箭头：

```
模型层 → 应用层 → 用户
   ↓
Infra 层（基础设施）
```

箭头单向，模型供应算力，应用调用模型，Infra 提供底层支持。

这是 2023 年的视角，今天已经失效。

真实情况是**三层互相影响，价值持续迁移**：

```
应用产生用户和任务数据 → 改进模型
模型能力变化 → 提出新的 Infra 需求
Infra 降低成本 → 催生更多应用
```

应用不是模型的简单客户，它也是数据和分发来源。

Infra 不是被动底座，它决定哪些模型能力可以进入生产。

模型也会向下改变应用和 Infra 的边界。

## 三层分别看

### 模型层

**核心资产**：研究、数据、算力、训练工程、推理

**壁垒**：前沿能力、成本、数据、品牌、开发者生态

**收入来源**：API、Coding、Chat、Agent、企业服务

**风险**：

- 开源追赶
- 价格战
- 技术同质化
- 资本开支过大
- 应用入口不足

**代表**：OpenAI、Anthropic、Google DeepMind、Meta、Mistral、DeepSeek、Kimi

### 应用层

**核心资产**：场景理解、用户关系、私域数据、品牌、工作流

**壁垒**：场景深度、用户粘性、工作流嵌入、模型可替换性

**收入来源**：订阅、交易抽成、广告、API 转发

**风险**：

- 上游模型直接覆盖功能
- 用户切换成本低
- 获客昂贵
- 模型供应商价格和政策变化

**代表**：ChatGPT、Claude、Cursor、Perplexity、Harvey、Replika、Character.AI

### Infra 层

**核心资产**：GPU、云、推理框架、Agent Runtime、Context、Evaluation、Observability

**壁垒**：标准化共性问题、规模效应、长周期客户

**收入来源**：算力订阅、平台费、企业合同

**风险**：

- 模型厂商自建
- 开源替代
- 模型进步消除需求
- 客户未成熟时过早抽象

**代表**：NVIDIA、AWS、Azure、CoreWeave、Databricks、LangChain、Weights & Biases

## 价值迁移的三个阶段

> 价值不会固定停在某一层，会随能力、成本、入口持续迁移。

![AI 产业价值迁移三阶段：模型稀缺期 → 模型商品化期 → Agent 平台期](../../images/2026-07-25-ai-twelve-themes/12-value-migration.png)

**底层逻辑**：模型能力稀缺 → 价值集中模型；当能力商品化 → 价值向应用迁移；Agent 时代 → 价值向控制点迁移。

### 阶段一：模型能力稀缺期

价值集中在：

- 模型本身
- GPU / 云 / 训练 Infra
- 顶尖研究人才

应用层差异被能力上限掩盖——做啥都「AI 还没那么强」。

这是 2022-2024 年的状态。

### 阶段二：模型商品化期

API 价格下降，开源追赶，模型能力趋同。

价值迁移到：

- 用户关系
- 品牌
- 工作流嵌入
- 私域数据
- 分发渠道

应用层差异化开始显现。

这是 2025-2026 年的状态。

### 阶段三：Agent 平台期

Runtime、Context、Memory、工具权限、身份、支付、任务入口可能形成新平台。

谁管理用户长期任务、谁掌握授权，谁可能拥有新分发权。

这是 2026+ 即将进入的状态。

## 跨层扩张

### 模型公司向下扩张

- API → Chatbot → Coding → Agent → 应用商店
- 代表：OpenAI（GPT → ChatGPT → Agent → Operator → App Store）

### 应用公司向上扩张

- 应用 → 微调 → 专用模型 → 自研模型
- 代表：Harvey（法律 AI → 自研法律模型）

### Infra 公司横向扩张

- 单点工具（GPU、存储）→ Runtime（Agent 编排） → Evaluation（评测） → 安全（governance）
- 代表：Databricks（数据湖 → ML平台 → AI Gateway）

跨层可以强化数据闭环和收入，但**也增加组织复杂度和资本需求**。

## 360° 经济结构

### 成本归属

- **模型层**：训练、推理、研究人才
- **Infra 层**：硬件、云、网络、存储、运维
- **应用层**：获客、产品、客户成功、责任

价值分析要看：

- 谁付出不可替代成本
- 谁控制收入入口
- 谁承担失败责任

### 毛利结构

- **模型 API**：毛利受推理效率、利用率、价格竞争影响
- **Infra**：受资源采购、规模、支持影响
- **应用**：还要扣除模型成本、工具成本、人工审核、渠道

收入增长但推理成本同步增长 → 不会形成软件式毛利。

### 议价权

议价权来自：

- 稀缺能力
- 切换成本
- 分发入口
- 数据

模型能力相似时，议价权下降；应用嵌入核心流程后议价权上升；Infra 如果是开放标准且替代多，议价权有限；平台掌握身份和分发时议价权最高。

## 数据究竟属于哪一层

我的判断是：

- **应用产生数据**：任务和反馈
- **模型需要数据**：训练
- **Infra 管理数据**：流和权限

数据价值取决于：

- 授权
- 质量
- 标签
- 独特性
- 能否进入闭环

**大量通用日志不是壁垒。** 高质量、可用于评测和训练的场景数据才可能形成优势。

## 几个反共识观点

### 1. 「跨层是趋势」是过度简化

不是所有公司都该跨层。关键是看你**控制什么**。

- 拥有最强模型 → 可以向下扩张
- 拥有最大用户 → 可以向上扩张
- 拥有共性需求 → Infra 有空间

### 2. 「模型商品化会毁掉模型公司」是误读

OpenAI、Anthropic 仍然通过 Coding、Agent、Chat、订阅在继续增长。

### 3. 「Infra 没护城河」不对

Infra 护城河在客户切换成本和长期合作关系。

### 4. 「应用 = 套壳」是侮辱

应用可以是真实价值创造。

### 5. 「AI 平台是新 App Store」是类比限制

AI 平台控制的是身份、Memory、权限，比 App Store 更深。

## 怎么判断一家公司处于哪一层

不要只看宣传身份，看下面 5 件事：

1. **收入来自哪里**：API？订阅？算力？
2. **核心成本是什么**：训练？推理？云？
3. **客户为何无法替换**：技术？流程？数据？
4. **数据从哪里产生**：用户行为？任务反馈？监控？
5. **控制哪个入口**：发布？分发？支付？

模型公司可能主要靠应用收入，应用公司也可能拥有 Infra 资产。

## 公司战略选择

### 路线 A：坚守单层

- DeepSeek：纯模型 + 推理
- 一些垂类 SaaS：纯应用

### 路线 B：跨层扩张

- OpenAI：模型 + Chat + Agent
- Anthropic：模型 + Claude Code + MCP
- 字节：模型 + 应用 + Infra

### 路线 C：Build-Buy-Partner

- 自建：差异化核心和高敏数据
- 采购：商品化能力
- 伙伴：快速变化的能力

### 路线 D：开放生态

- 平台提供 Runtime + 工具市场
- 第三方做应用
- 代表：阿里云百炼、字节扣子

## 关键认知

- 三层价值会随能力、成本、入口迁移。
- 模型商品化后，场景、用户、工作流、分发重新重要。
- Infra 必须证明问题是长期共性，而非短期模型缺陷。
- 最危险位置是既没有模型优势，也没有用户关系和工作流的薄层。
- Agent 时代可能围绕 Context、Memory、权限、身份、支付形成新平台。
- 最强公司可能跨层，但跨层不是免费午餐。

## 观察指标

- 模型 API 价格和开源替代速度
- 应用留存、收入、模型切换成本
- Infra 独立客户、毛利、续费
- 模型公司向应用扩张的效果
- Agent 平台是否形成分发、交易、身份入口

## 写在最后：12 篇结束之后

读到这里，你应该已经有一套完整的 AI 产业判断框架。

但请记住几件事：

1. **数据在变**：今天讲的 12 条主线，2027 年可能有 3 条要改写
2. **认知要更新**：每 6 个月回看一次，更新自己的判断
3. **不要押单一主线**：AI 行业的真正赢家往往是跨主线布局的
4. **第一性原理**：当你听到一个新概念，问「它解决什么真问题」「它在哪一层」「它的护城河是什么」
