## 三个让人焦虑的词

「超级个体」「一人公司」「AI 副业」。

这三个词在公众号、知乎、小红书、X 上刷屏。每个人都在担心：

- AI 会不会让我失业？
- 我能不能成为超级个体？
- 我的孩子未来该学什么？

我自己的判断是：**恐惧被夸大了，机会也被夸大了。**

## 先理清概念

我严格区分三个层级：

- **任务（Task）**：可被自动化或辅助的具体工作
- **岗位（Job）**：一组任务的组合，对应一个职业身份
- **组织（Org）**：一组岗位的协作，对应一个公司或机构

> AI 的影响是：**任务 → 岗位 → 组织**，自下而上。

### 任务层：AI 已经在替代

- 写邮件：被 AI 替代
- 改代码：被 AI 辅助
- 翻译：被 AI 替代
- 数据分析：被 AI 辅助
- 客服：被 AI 替代

几乎所有「重复性 + 结构化」的任务都在被接管。

### 岗位层：开始重构

岗位 = 任务组合。部分任务被自动化后，岗位仍然存在，但内容变了。

- **客服**：基础咨询被替代，复杂投诉仍需人工
- **翻译**：日常翻译被替代，本地化协调仍需人工
- **设计师**：基础设计被替代，创意与决策仍需人工
- **程序员**：重复编码被替代，架构与维护仍需人工

不会出现整个岗位消失，但岗位内容的 40-70% 会改变。

### 组织层：刚开始

只有当岗位内容大幅变化后，组织才会重构。

预计 2025-2030 年，AI 公司的组织形态会显著变化：

- 一人公司 + AI Agent 增多
- 中层管理减少
- 高层级决策权保留
- 跨职能团队增多

## 超级个体的真实定义

「超级个体」这个词被滥用。

我的定义：

> **超级个体 = 个人控制核心知识 + 客户关系 + 借助 Agent 扩展执行半径。**

注意三件事：

1. **核心知识**：行业经验、领域 know-how、品味
2. **客户关系**：直接面对最终客户
3. **Agent 扩展**：把执行类的任务放给 Agent

一个人不能同时是「研究 + 工程 + 设计 + 销售 + 客服」，但可以**控制这些环节的设计标准**，让 Agent 执行。

## 能力栈拆解

我把超级个体的能力拆成 5 层：

```
┌────────────────────────────────────┐
│ 5. 财务与风险：定价、税务、保险、合约 │
├────────────────────────────────────┤
│ 4. 内容与销售：写作、演讲、品牌、增长 │
├────────────────────────────────────┤
│ 3. 技术编排：AI 工具、自动化、Eval    │
├────────────────────────────────────┤
│ 2. 产品能力：需求、UX、迭代、协作     │
├────────────────────────────────────┤
│ 1. 领域知识：行业 know-how、问题理解  │
└────────────────────────────────────┘
```

AI 可以弥补 3-4 层的执行，但替代不了 1-2 层的判断。

优势：1-2 层做的越深，AI 帮你放大越多。

风险：只懂 3-4 层，AI 也会替代你。

## 5 类典型超级个体

### 1. 领域专家 + 内容

- 律师 / 医生 / 工程师 / 设计师
- 用 AI 写文章、做客户教育
- 收入：订阅 + 课程 + 咨询

代表：Lex Fridman（播客 + 多领域）、Simon Willison（技术博客）

### 2. 创业者 + 一人公司

- 一个人做完整产品
- AI 帮你写代码、做设计、客服
- 收入：SaaS 订阅 + 服务

代表：Pieter Levels（Nomad List）、Marc Lou（ShipFast）

### 3. 创作者 + AI 工具

- 设计师 / 插画师 / 音乐人
- 用 AI 加速创作
- 收入：作品销售 + 平台分成

代表：很多 X 上小有名气的 AI 创作者

### 4. 顾问 + AI 工具

- 行业顾问、营销顾问
- AI 辅助报告、PPT、整理
- 收入：项目费 + 长期合作

### 5. 投资人 + AI 研究

- 用 AI 辅助尽调、监控
- 收入：投资收益 + 顾问费

## 收入结构

真实可持续的超级个体收入往往是**组合**：

```
订阅产品（40%）+ 项目服务（30%）+ 内容/课程（20%）+ 投资/伙伴（10%）
```

单一渠道很危险：

- 纯订阅 → 平台依赖
- 纯服务 → 时间受限
- 纯内容 → 平台流量波动

「一人公司」听着浪漫，但**多渠道比单一渠道更稳**。

## 几个反直觉观察

### 1. 「超级个体」其实很累

以为一个人更自由，实际更累：

- 没有同事分担
- 没有组织保护
- 没有团队兜底
- 所有决策都自己扛

要可持续，必须会拒绝、会上线新 AI 工具、会给自己放假。

### 2. 「收入翻倍」常伴随「时间翻倍」

单位时间收入可能提高，但总劳动时间也提高了。

### 3. 「AI 替代员工」其实不便宜

- Cursor 订阅：$20/月
- Claude Code：$100-200/月
- GPU 推理：$1000+ / 月
- 工具链 + 数据：$500+ / 月

算下来一年 $30K+。这也是真实成本。

### 4. 「孩子未来学什么」不是单一答案

未来 20 年变数太大。培养 4 件事：

- 学习能力（学什么都能学）
- 提问能力（找到真问题）
- 协作能力（与 AI 也与人）
- 审美能力（不容易被 AI 替代）

### 5. 「副业一定发光」是幸存者偏差

绝大多数副业失败。少数成功是因为：

- 已有平台流量
- 已有领域积累
- 已有客户关系

从零开始做副业，成功率 < 5%。

## 职业变化的四种类型

| 类型 | 描述 | 例子 |
|---|---|---|
| 增强型 | AI 提升效率，岗位不变 | 程序员、设计师、律师 |
| 重组型 | 职能边界模糊，岗位重定义 | AI 产品经理、全栈工程师 |
| 压缩型 | 基础岗位人数下降 | 初级客服、初级翻译 |
| 新生型 | 完全新岗位出现 | FDE、Agent 运营、Eval 工程师 |

未来 5 年大多数岗位是「增强型」+「重组型」。纯压缩型会发生在重复性最强的工作上。

## 关键认知

- AI 影响是「任务 → 岗位 → 组织」三层，自下而上。
- 超级个体不是全能，是控制核心 + Agent 扩展。
- 领域知识 + 产品能力是护城河，AI 工具只是杠杆。
- 收入需要组合，单一渠道危险。
- 职业变化是 4 种类型混合，不是单一方向。
- 学习能力、提问能力、协作能力、审美能力是底层。

## 学习路线

如果你想成为超级个体，按这个顺序：

1. **先深耕一个领域**：找到你愿意花 10000 小时投入的事
2. **学产品能力**：理解需求、UX、迭代
3. **学 AI 工具**：Cursor、Claude Code、Comfy UI、Make 等
4. **做一个小产品**：验证 PMF
5. **建立客户关系**：直接对话用户
6. **搭建自动化系统**：把执行尽可能交给 Agent
7. **扩展内容渠道**：写作、播客、视频
8. **跨平台运营**：不要依赖单一渠道
