## 一、愿景、善意与“克制”

**梁文锋：**

欢迎各位投资人。

我们一开始做这个公司，没有想过最后要赚多少钱、到资本市场上市。最开始的几十个人也完全没有这么想过；如果一个人只想着这些，他可能就不会来。

总体来说，我们怀着对这个世界非常大的善意来做这件事。我们觉得它对人类有用，是金钱以外的事情。当然，后来发现其中利益非常大，也会出现其他诱惑，这是另外一回事。但我们的初衷和保持到现在的愿景，不是按照商业利益最大化的方式做事。

大约二十年前，在管理上我最崇拜杰克·韦尔奇。现在回头看，他说的大部分东西可能已经不对了，但有一点很重要：一个公司最重要的是愿景。管理大公司靠的不是规章制度，而是愿景。

愿景不是挂在墙上的标语，而是你实际怎么做、怎么运行。我们怎么管理和组织这么多人？其实我们没有严格的组织，是靠愿景驱动的。这有好处，也有坏处，未来我们会想办法扬长避短，但这是我们的特色。

我们不是靠 KPI 和考核做事，只有愿景。这个愿景甚至没有形成文字，从来没有正式写出来过，而是体现在我们做事的方法和对待世界的态度里。公司每个人对它的理解可能略有不同，但大的方向是一致的：怀着对世界的善意，想做一点有用的事情。

这也解释了我们为什么坚持开源。因为愿景本身就要求开源。没有这样的愿景，也很难把人组织起来。有些公司的开源带着一种被迫的感觉，但对我们来说，开源本来就是我们的本意。

我们一开始就想得很清楚。第一是愿景；第二是我们认为，要把 AI 在商业上做成，开源反而有好处。

历史上，开源和商业化常常有冲突。一个软件公司的市场一年可能只有几十亿美元，一旦开源，收入可能只剩几千万或几亿美元。但 AI 不一样。AI 最终可能占人类社会 GDP 的 10%，这是一个非常大的数字。

一个人不可能独占这件事。你一定要跟别人分享，否则就活不下来。如果想独占全部利益，一定会被历史抛弃。你会遇到很多阻力，也会出现其他方法阻止你实现目标。

因此，不能完全按照传统商业思维做，需要有一套机制确保自己获得的利益是有限的。**需要克制。** 如果想在自己手上把 AI 做成，就不能想着人类 GDP 或中国 GDP 的多少都归自己。越这么想，越做不成。

我们两年前成立时，没有很多钱、很多卡、知名度和号召力，就是一群非常平凡的人。我喜欢“一群平凡的人做出不平凡的事情”这个叙事，而不是一群天才做出不平凡的事。这与克制和愿景是一脉相承的。

AI 的利益足够大，只要最后能做成，随便分到一点就已经很多。所以现在根本不用考虑以后拿哪一部分、怎么拿。我们只赚取合理利润，看重长期意愿，而不是眼前利润有多大。

### API 的定价逻辑

我们的 API 定价标准，是买一批设备回来，大约十个月收回设备成本。财务上服务器可能按三年或五年摊销，但商业上考虑风险、前期投入等因素，十个月回本，我们觉得已经足够。

V3.2 Flash 和其他模型采用的都是这套逻辑。它不是利润最大化定价。如果追求利润最大化，价格应该更高，因为在目前价格区间，用户需求没有那么强的弹性：价格提高一半甚至一倍，Token 消耗量可能不会减少很多，收入反而会接近翻倍。

我们有一款模型，一开始担心需求太多，所以把价格定得比较高，团队里大家不太高兴。后来我把价格降到原来的四分之一，大家就很开心。这个才是我们真实的想法。

我们做模型的目的，是希望它价格便宜、效果好，让大家能够充分使用。降价时，公司群里很多人欢呼，因为大家觉得自己花这么多精力把模型做好，终于可以让更多人用得起。这是我们的动力和内部共识。

有人说十个月回本的利润还是太高。确实还有降价空间，模型优化也还有空间。但这个成本水平我们能做到，其他公司未必做得到。我们没有继续降价，是因为需求已经缺乏弹性：现在的价格大家都用得起，再降价不会显著增加需求，对社会幸福感的提升也有限。

所以，定价不是以公司收入或利润最高为出发点。从短期看，价格高一点可能收入更多；从长期看不一定。对我来说，**克制是一种战略**：有时舍弃一些，可以换来更多其他东西。

开源也是让利的一部分。对公司内部来说，大家会因此获得成就感和凝聚力；对社会来说，同行和普通用户都会受益。从长远看，这种克制能够增加我们做成 AGI 的概率。

### 为什么不争夺所有商业机会

我毫不怀疑 AGI 有非常大的商业价值。在这个基础上，我优先考虑的不是多拿一点份额，而是怎么提高做成的概率。

去年春节用户突然增加，但我们没有想办法强行留住用户、立即变现，或把它做成下一个超级 App。我们可以这么做，但没有做。我们不想有了用户后，就去跟字节争夺流量，试图成为下一个字节或腾讯。

如果去年投入大笔资金和字节抢用户，也是一种打法。但我们选择了克制，因为后面还有西瓜，前面可能只是芝麻。我不应该停下来，把每一粒芝麻都当作最重要的事情。

现在回头看，去年没有在 C 端全力投入，可能是对的。我们仍以较低成本维持用户服务，因为这些用户未来可能有用；顺手能拿到的机会，我们也会拿，但不会因此偏离主线。

今年 API 或 B 端收入也可能形成机会。如果需求继续增长、能买到更多显卡，ARR 做到几亿美元是有可能的。如果接近十亿美元，公司现金流可能转正，覆盖研发和其他费用。

这个事情我们会做，也会做好，但它不是第一优先级。与 AGI 相比，去年的 C 端和今年的 B 端都不是同等重要的问题。

## 二、开源、商业模式与产业生态

**梁文锋：**

我们会继续开源，最强的模型也可能开源，因为我看不到闭源有什么必然的好处。

即使把模型和很多细节都告诉别人，真正用起来的门槛仍然很高；要把部署成本做到很低更难。原理大家可能都明白，但不是每家公司都有意愿和能力组织人力去完成这些工作。大公司有管理和物理约束，太小的创业公司又没有足够力量。我们目前的规模可能刚好处在一个甜蜜点。

即使模型开源，我们的 API 也不会收很高的费用，仍然可能按十个月回本定价。这个价格已经足以让独立部署的第三方无利可图，因为第三方很难做到我们的成本。

如果目标是赚一百倍利润，开源当然会影响利润，因为第三方即使成本高二十倍，也可能比你便宜。但如果只赚合理利润，开源和商业模式就没有冲突。

我不担心别人部署我们的模型与我们竞争，反而希望他们能部署起来。我们愿意尽可能为开源社区提供帮助。我只担心他们某些细节没做对，效果变差，或者成本过高。

去年也有人问：模型开源之后，腾讯等有大量流量的公司会不会部署我们的模型，把 C 端用户都抢走？实际并没有发生。我们给出的开源模型与自己部署的模型是一样的，不会开源一个弱模型、自己留一个更强模型。去年一整年已经证明，开源与 C 端服务之间没有明显冲突。

### 利润为什么会走向合理区间

如果 AI 最终占全球 GDP 的 20%，一家公司想独占其中 5%，在账面上可能算得过来，但它一定会被另一个只想拿 1% 的人打败；后者又可能被愿意只拿 0.1% 的人打败。

拿得多的人会被拿得少的人打败，甚至还没真正拿到钱，只要愿景表现为“我要拿得更多”，组织就会先遇到更大阻力。

当然，拿得太少，公司商业逻辑不成立，也活不下去。所以最终会出现平衡：拿太多会被竞争者打败，拿太少又无法持续经营。我们追求的是合理收益，而不是收益最大化。

### 基础模型公司会逐渐收敛

国内做基础模型的公司太多了。美国可能主要是三家，中国的资源却分散在很多团队中，每一家都重复做相似的事情、拿到更少的资源。

这种局面最终一定会收敛。如果大家发现基础模型没有想象中那么高的利润，一部分公司就不会继续做。中国最后可能有三四家，两家大公司、两家小公司，竞争已经足够充分。

基础模型公司不可能拿走产业的大部分利润。模型之间最终的差距没有那么大，主要体现在时间和成本：谁先做出来，谁能以更低成本提供。成本控制好就多赚一点，控制不好就少赚一点，仅此而已。

我们希望扶持更多生态伙伴，在利益上没有冲突，但有没有足够时间和精力去做，是另一回事。我们的态度是合作共赢，而不是把所有应用都做掉。

### 商业化仍然是公司生存的基础

我们一直在商业化，只是没有以商业化为目标。我们以 AGI 为目标，但有 C 端用户，也有 B 端收入。从历史经验看，这个策略是成功的。

我们离彻底转向商业化应该还很远。在可见的未来，把技术继续向前推进，收益仍然比扩充产品线、设计更多商业模式更大。

过去三年，任何时候如果花大量时间研究商业化路径，最后很可能都是广告、电商、本地生活等传统答案，但产品变化太快，这些规划生命周期很短。

我们希望商业机会由整个社会和合作伙伴共同完成，而不是全部由自己独吞。我们没有那么多精力，也没有那么多人做所有事情。

但我们本质上仍是一家公司，不是 Bell Labs。政府不会给我们一分钱，我们必须考虑怎么活下去。B 端业务以后可能非常重要，只是当前它还不是最重要的研究目标。

如果未来技术不再进步，最坏情况下，我们可以全力把 API 服务做好。现有的 C 端用户和 B 端收入，也足以为一家商业公司提供基础。我们希望有更大的梦想，但也有可以拿出来的保底业绩。

## 三、AGI 路线：从 CoT、Agent 到持续学习

**梁文锋：**

我们的长期目标应该是 AGI。每个人对 AGI 的定义不一样，但不妨碍我们把它作为目标。从技术路线看，这条路线图相对清晰。

当前这一代 AI，如果一个问题能够描述清楚，并给予完整上下文和指令，它在很多任务上已经超过人类。但“完整上下文”这个前提在现实中很难满足。

比如今天开会，每个人背后都有几十年的上下文，AI 并不具备。你招一个员工，他花两个月熟悉公司环境、工作和同事，之后听到“叫小王过来”，就知道小王是谁、在哪里、应该如何联系。

对 AI 来说，你必须说明小王是谁、担任什么职务、在哪里、怎样找到他、沟通时需要注意什么。虽然给足上下文后 AI 可以做，但现实中不可能每次都提供所有信息。

如果 AI 具备持续学习能力，能像员工一样在公司学习两个月，它就可能替代很多人的工作。所以下一个关键台阶是“学习如何学习”。

### 智能发展是一组阶梯

AI 的发展可以理解为阶梯：

1. 最早的阶梯是语言模型；
2. 去年的重要阶梯是 CoT，也就是思维链；
3. 今年的阶梯是 Agent；
4. Agent 之后的瓶颈是持续学习；
5. 持续学习之后，可能进入 AI 自我迭代的阶段；
6. 再往后才是具身智能。

后一步建立在前一步之上。Agent 需要 CoT，CoT 需要语言模型，所以之前每一步都不是白走。

CoT 发展到上限后，模型可以在奥数、编程等任务上超过顶尖人类，但仍然不是 AGI。Agent 会扩大模型可解决问题的范围，但也会走到能力上限。到那时，它仍无法像员工一样长期学习。

持续学习可能让模型完成所有人类能够完成的知识工作，也让它帮助开发自己的下一版本。所谓“奇点”可能不是突然发生的点，而是一个连续但非线性的渐进过程，因为 AI 可以加速 AI 研究。

我们希望先解决持续学习，再借助它完成自我迭代，之后才进入具身智能。这条路线最轻松，因为每一步都可以利用前一步的能力帮助开发后一步。等 AI 能自我迭代后，再做机器人和具身智能，就不完全需要人来做了。

如果路线反过来，先做具身智能，就会变成很苦、很重的工程。我们希望选择更省力的路线。

### 持续学习还没有成熟方法

持续学习不是一项单一技术，而是一个问题，可能需要很多种技术共同解决。全世界都在研究，目前还没有找到真正有效的方法，大家仍处于摸索阶段。

我们有很多思路，也有一些看起来有前途的想法，但还没有做通。它通常不需要像训练大模型那样消耗大量卡和人力，更多需要研究者不断思考和尝试。我们内部把它叫作“摸奖”：门槛不高，谁都可以摸，但谁能摸出来，不知道取决于天赋还是别的因素。

它不是一个需要集中大量人力的工程项目，而是公司会长期讨论、持续思考的重要问题。

### 下一代模型首先要帮助 DeepSeek 自己

我们内部比较看重一个叙事：下一版模型应当帮助我们开发下一版模型，提高 DeepSeek 自己的工作效率。

模型的第一目标不一定是让外部用户觉得好用，而是先让我们自己好用。它如果能帮助研究和工程团队更快开发下一代，就能加速实现 AGI。对我们有用之后，通常也会对其他用户有用。

现在已经能确定，AI 可以帮助我们实现 AGI。它还不能完全自主工作，但与人配合已经很有价值。如果先解决持续学习，AI 的能力会更强，通用智能也可能更容易实现。否则完全靠人工推进，会是数据密集、人力密集而且很辛苦的过程。

### 世界模型、多模态与具身智能

我们只做 AGI 的主线。AI 领域很广，3D、视频生成等方向在当前阶段与智能上限没有太大关系，因此我们不会把它们作为主线。

世界模型的定义比较宽泛，很多东西都可以叫世界模型。按照我们的判断，现在最重要的仍是把 AI 训练做好，再解决持续学习。世界模型和视频生成目前不是最关键的障碍。

视频生成在商业上可能是好生意。Sora 出来时，大公司、小公司都做，后来很多小公司又砍掉了。我们不会因为一件事商业上好，就一定去做；只有它位于智能路线图上，才会成为核心方向。

多模态则是重要组件。对 C 端产品来说，它很重要，我们也一直在做，后续模型会支持原生多模态。但从智能上限来看，多模态与搜索类似，都是组件，不是主线本身。

最终具身智能仍然绕不过去。正常人的需求不是操作电脑，而是衣食住行、吃喝玩乐和现实中的服务。如果目标是解决人力需求，AI 最后一定要进入现实世界。

没有具身时，我们希望 AGI 能帮助迭代下一版模型；有了具身后，我们希望它能帮助制造下一代机器人。

### Scaling 仍然有效

我们相信 Scaling。规模越大，效果越好，也能解锁更多能力。阻止我们 Scaling 的是算力，而不是我们认为模型已经足够大。

模型规模是按照可用资源倒推出来的：有多少算力，就训练多大模型。目前收益仍然明显，我们还没有机会触及 Scaling 的上限。

硅谷讨论 Scaling 是否到头，是因为他们已经走得更远；对中国团队来说，数据 Scaling、模型规模 Scaling 和训练成本的上限都还离得很远。

## 四、算力瓶颈与国产芯片

**梁文锋：**

我们与美国的主要差距只有一点：资源。我们没有那么多卡。

原稿中提到，DeepSeek 当时约有两万张 H 系列等效算力，其中大部分是最近一两个月到货，后续还会继续购买，基本以英伟达为主。我们的策略是，在能够承受、价格合理的范围内，能买多少就买多少。

如果融资的钱能在半年内全部变成显卡，那是非常理想的事。把钱放在银行收益很低，而显卡可以通过服务产生现金流。现实问题不是愿不愿意买，而是买不到足够数量且价格合理的卡。

> 整理者注：以上及下文卡量、采购金额和芯片性能对比均来自流传文字稿，未经独立验证。

### 人才差距本质上也受算力影响

中美在人本身的差距没有那么大。国内人才基数很大，每年也有大量新人。人才不是主要瓶颈，资源才是。

算力会影响人才培养。算力少，能做的实验少，研究人员成长就会变慢。所以很多看起来是人才、模型和应用上的差距，本质上都可以追溯到算力资源差距。

人才工资在 AI 总投入中的占比并不高，真正的大头仍然是算力。即使美国公司给个别人才开出极高薪水，和整个训练、研究集群的投入相比，仍然不是最大部分。

在最大模型上，国内目前很难与美国直接竞争。原稿提到，美国前沿模型的激活参数规模可能达到约 800B，而国内更多停留在几十 B。要训练同等规模模型，可能需要约五万张 GB300，或者二十万张华为 950 等级的卡，而且这还没有计算研究实验所需资源。

因此，我们不会直接在最大规模上竞争，而是先在几十 B 激活参数范围内把事情做好，等资源增加后再逐步扩大到 150B、250B 等规模。

在总算力存在数量级差异时，全面超过美国并不现实。但中国团队可以在重点方向有所取舍，在某些领域超过，并通过算法与工程效率缩短时间差。

过去的叙事可能是：晚美国一到两年，用其二十分之一的算力做出类似能力。未来希望把时间差缩短到六个月、三个月，并把算力差距缩小到几分之一。

### 国产芯片的历史性机会

国产卡过去最大的问题是生态。买到卡却用不起来，没有英伟达 CUDA 那样成熟的软件环境，所以英伟达的护城河很强。

但事情正在变化。

第一，有了 AI 之后，构建软件生态更容易，因为 AI 可以帮助写代码。第二，出现了 TileLang 这样的高级语言，可以更快地编写算子。第三，AI 计算卡市场已经超过游戏卡，以后专用芯片不再需要和游戏卡生态强耦合，CUDA 原有优势会减弱。

原稿称，V3 虽然使用英伟达硬件训练，但已经尽量减少对英伟达软件生态的依赖。通过高级编译层和 TileLang 完成算子开发，再将这一套流程迁移到华为卡上，国产适配问题就有机会被解决。

TileLang 可以显著减少代码量和开发时间。相较于手写底层代码，执行效率可能损失 1% 到 2%，但这是可以接受的。文本还提到，团队在尝试用 AI 编写 TileLang，不过当时的 TileLang 代码仍主要由人完成。

我们认为，未来一年可能会逐渐证明国产芯片生态可以做好。真正更难的问题是产能。

### 华为芯片、性能与生命周期

原稿提到，DeepSeek 主要与华为合作，获配约一万六千张华为 950。按照文中的折算，这约相当于四千张 B 系列英伟达卡，只够训练当前一代模型，不足以训练下一代更大模型。购买和适配这些卡，一个重要目的也是帮助国产生态成熟。

文中判断，华为超节点能够完成 GB200、GB300 能完成的任务，但代价是需要更多卡、能耗更高，并在产品代际上落后约两年。原稿将差距概括为“四倍加两年”：约四张华为 950 对应一张 GB300，同时发布时间落后两年。

在价格上，即使国产方案贵 50%、100% 甚至更多，只要能完成任务，在无法购买英伟达卡的环境中仍然具有替代价值。

折旧周期也会不同。英伟达卡大致可以按五年折旧；华为卡因为起点已经落后，可能更适合按三年折旧。它今年、明年仍可用，但再往后可能因为能耗而失去经济性。

国产硬件追赶需要几年。生态问题有望先解决，产能问题今年、明年、后年可能仍然存在。但从五年尺度看，不太可能永远卡在产能上。

### 是否自建集群与自研芯片

大型集群肯定会自己建设，我们的集群一直是自己建的。但是否自研芯片，要看收益是否足够大。

一个运营发电厂的公司不一定要自己造发电机，只要能以合理价格买到设备，就没有必要什么都做。我们希望聚焦一块，不向上游垂直整合，也不向下游把所有应用都吃掉。

AI 足够大，未来可能出现很多万亿美元公司。只做其中一小块，也足以成为其中一家。没有必要因为市场大，就什么都自己做。

## 五、成本、数据与产品方向

**梁文锋：**

模型竞争最终可能不会有特别大的能力差距。差别主要体现在三方面：成本、时间和用户体验。

第一是成本。提供同样质量的服务，谁能以更低成本完成，这是很强的壁垒。第二是时间，同样的能力早几个月或晚几个月做出来，意义不同。第三是用户体验，它会带来一定粘性，但可能没有前两项那么本质。

比较模型效果必须在相同成本下进行，就像比较同价位的汽车。优秀模型和较差模型之间的区别通常不是某一个环节，而是整体系统能力。

### 为什么特别重视计算效率

不是所有公司都在意模型效率。对一个利润导向的商业公司来说，服务成本下降未必是第一优先级；成本低了，价格也可能下降，收入反而减少。

但低成本是我们愿景的一部分。团队成员都是普通人，知道用户使用模型需要花钱，对别人能否负担得起有同理心。大家希望把成本继续做低，特别是在中国算力紧缺的背景下，希望模型能被更多人使用，也能在国产卡上运行。

低成本还是扩大模型规模的前提。在相同算力下，计算效率越高，就越能训练和服务更大模型。大公司可以通过增加资源解决一部分问题，我们则会优先考虑成本效率。

### 高质量数据与后训练

数据几乎等于模型的一半。当前模型能力提升很大程度依赖数据和后训练。

我们与海外团队的主要差距之一，是高质量数据标注。高端数据标注在中国没有明显成本优势，国内和美国都很贵。以我们的资本投入结构，很难像美国公司那样大规模承担高质量标注成本。

但瓶颈不完全是钱，更重要的是时间。OpenAI、Anthropic 等公司开始得更早、资本和卡更多，而国内可以认为最近半年才大规模开始。即使资金充足，团队扩张和流程成熟也需要时间。

原稿称，公司可能有一半核心研究人员在参与数据相关工作。我们先做成本较低的标注，同时逐步扩大高质量数据能力。预计在一年左右，国内高质量数据问题有望得到明显改善。

合成数据和真实数据都可能发挥作用。像 AlphaGo 能走出人类从未见过的棋，说明 AI 可以在已有知识基础上超越人类。它可能仍有局限，但目前还看不到边界。未来不会只有单一的数据方法。

### 幻觉问题

模型幻觉有办法改善，可以通过更好的 Post-training 逐步解决。它是一个长期问题，但并非无解。

对我们来说，幻觉既是模型问题，也可以被归为产品问题。我们会解决，但当前不是最核心的研究重点。

### 为什么先做 Coding Agent

对于纵向的金融、法律、医疗 Agent，我们还没有完全想清楚国内商业模式和最顺利的路径。国内情况与海外不一定相同。

现阶段更合理的做法，是优先做好通用 Agent，尤其是 Coding Agent。Coding 能力可以直接帮助模型研发，也能扩展到很多任务，因此优先级高于金融、医生等垂直 Agent。

## 六、组织方式、团队稳定与决策机制

**梁文锋：**

对我们来说，最大的核心利益只有一点：保持团队稳定。这甚至可以认为是唯一不能让步的利益。

只要团队保持稳定，大家都不走，我们就一定有机会做成 AGI。即使遇到挫折，也可以继续尝试。资金、资源和其他要素相对容易获得，最多让我们晚半年或一年；团队一旦失去，就很难重建。

近期融资在一定程度上降低了风险，因为员工期权数量和金额相对可观。只要重要的老员工稳定，其他人通常也不会轻易离开。大家并不完全为了钱而来，也希望留在一个有机会实现 AGI 的环境中。

从历史看，我们的人才流动比同行少，但团队稳定依然是最大的挑战。我们做很多事情，都会考虑它是否有助于团队稳定。

### 两条管理线

公司管理有两条线。

一条是从上到下。公司要集体完成某个目标，比如发布 V4，就需要明确分工、让不同团队协作。我们把这类工作叫“做正事”。

另一条是从下到上。每个人可以自己判断想做什么、什么问题重要，没有统一 KPI，也不需要所有研究都事先审批。只要算力和公司资源能够支持，就可以自行探索。

理想情况下，“正事”不要占员工全部时间，最好不超过一半。剩余一半时间不被安排，由研究人员自由探索。

我们一般不太加班。第一，研究需要松弛环境，逼得太紧就很难产生真正探索。第二，我们非常聚焦，做的事情少，就没有必要把每个人的任务塞满。你会看到我们的很多产品并不完善，因为我们选择不去补所有细节，这也是克制的一部分。

### 决策建立在共识上

公司重大技术和业务决定建立在共识上，不是我一个人决定所有事情。

我的权威和影响力也是建立在共识基础上的。想推动一件事，首先要看大家是否愿意做、是否认可。我可能会引导方向，但引导作用有限。只有形成共识，事情才能真正推下去。

随着公司人员增加，这种完全分散的方式必须调整。未来有些部门需要严谨层级，另一些研究部门则会继续保持松散和扁平。我们已经开始做这种调整，否则很多事情无法推进。

### 没有可以直接模仿的组织

我们没有明确模仿对象。每一步都是从实际情况出发，分析利弊后作出的选择。它不是因为看到某家公司这么做，我们就照着做，而是现实环境下形成的结果。

我们和 Bell Labs 不同。Bell Labs 可以明确不承担商业化压力，但我们必须商业化、必须活下去。历史上也有很多公司拥有利润之外的追求，这不妨碍它们成为好公司，反而可能让商业化做得更好。

我们仍要判断赚哪些钱、什么时候赚钱、赚多少、靠什么赚钱，只是会有所取舍。

## 七、与合作伙伴和竞争者的关系

**梁文锋：**

除了团队稳定这一核心利益，其他方面我们都可以克制。我们不愿意与任何互联网大厂或创业公司成为敌人，更希望赋能和协助大家。

即使是阿里、智谱、月之暗面等同行，我们也愿意帮助他们把模型做得更好。既然本来就开源，就应该把边界和复现方法说清楚。如果对方复现不了，我们可以告诉他们细节，不会因为对方是竞争者就完全拒绝。

如果是合作伙伴，我们会做更多，但在大的利益上没有冲突。

我们只做 AGI 主线，视频、3D、很多垂直应用等方向可以由其他公司完成。我们希望 AI 被用到各种生产环境，帮助各行各业提高效率。是否有时间和人手帮助，是执行问题；利益上并不冲突。

过去的经历表明，善意和开源并没有让我们损失商业利益。C 端用户仍然很多，B 端增长也相对乐观。我们的善意甚至可能带来额外加分。

融资合作伙伴也是经过选择的，希望彼此利益一致，对我们没有敌意，并真正希望公司成功。不是所有人都希望我们成功，因为技术和价格变化仍然会影响一些既有利益。

### 不向所有方向垂直整合

我们不希望向上游、下游做过多垂直整合。只想做最擅长、认为最核心的一块，而不是把所有价值都拿走。

对 To C 和 To B 而言，有时越想完整闭环，反而未必做得最好。我们希望行业伙伴负责他们更擅长、更接近用户的环节。

To B 业务的上限在当前技术条件下仍受需求限制。需求会快速增长，但不是无限的。随着模型能力继续突破，新的需求才会不断出现。

## 八、现场问答补充

### AGI 还需要多久，国产硬件能否追上

**投资人：**AGI 还需要多久？国产硬件在这个时间内能追上吗？

**梁文锋：**

按照现在的 AI 范式，国内一两年内有机会做到与国外模型接近，甚至今年就可能在部分能力上平替，但这还不是 AGI。至少需要具备持续学习，才更接近我们所说的下一阶段。

国产硬件追上可能需要几年。要先解决生态信心，再解决产能。今年、明年、后年可能仍受产能限制，但我不相信五年后还会一直卡在这里。

### AGI 是否存在临界点

**投资人：**你提到 AGI 是渐进过程，是否意味着它没有临界点？

**梁文锋：**

它没有明确临界点，但可能是非线性的。AI 能加速 AI 研究，所以能力增长到后面可能越来越快。

语言模型 Scaling 目前还没有看到上限，至少以我们和美国当前达到的水平，都还没有看到。

### AI 是否缺少品味和直觉

**投资人：**过去 DeepSeek 强调研究方向选择中的品味和直觉。如果 AI 能自我进化，品味、taste 和直觉还重要吗？

**梁文锋：**

AI 现在不缺品味和直觉，缺的是持续学习能力。让它写文章时，它的品味和直觉没有明显问题。真正限制它的是不能有效地长期积累经验。

### 如何平衡确定目标和未知研究

**投资人：**Coding Agent 是相对确定的 Scaling 目标，持续学习则是尚未解决的研究问题。应如何分配研究资源？

**梁文锋：**

持续学习研究不一定占用大量资源。它不需要很多卡，也不需要成为一个固定的大项目，更依赖很多人持续思考。真正训练和发布模型、做效率实验，才需要大量人和算力。

我们与其他公司的区别，是会认真讨论这些未知问题，把它们放在重要位置，但并不意味着必须划出巨额资源。

### 中国 AI 的结构性优势

**投资人：**中国模型未来在哪些方面可能超过美国？

**梁文锋：**

中国可能在成本和产品体验上形成结构性优势。成本方面，海外公司未必足够重视，我们却可以把它视为核心能力。产品方面，中国公司的产品能力并不弱。

除了成本和产品，目前不一定存在其他明显的结构性优势。

### OpenAI、Google 与 Anthropic 的竞争

**投资人：**Anthropic 现在超过 OpenAI，这会是长期趋势吗？

**梁文锋：**

不一定。OpenAI 和 Google 未来大概率仍会交替上升。Anthropic 在 Coding Agent 上有先发优势，但没有达到碾压 OpenAI 的程度。我们公司内部也有相当一部分人认为 OpenAI 的方案更好。

这三家公司都很强。Anthropic 的效率可能更高，花掉的成本相对少，但先发优势未必能长期保持。

### 模型版本和发布节奏

**投资人：**后续模型版本和节奏如何？

**梁文锋：**

对我来说，比较舒适的发版节奏大约是两三个月一版。如果没有意外，应该一版比一版更好。

在约 50B 激活参数的尺度上，推理速度和效果可能逐步接近同规模开源模型。但与未公开的大尺寸模型相比，差距仍然存在，可能需要 150B 甚至更大的激活参数规模。

> 整理者注：原始转录中的模型名称、月份和部分版本号存在明显识别错误，相关内容未作确定性修正，具体发布计划应以官方公告为准。

### 资本市场与长期研究如何平衡

**投资人：**如何平衡纯粹科研、AGI 方向与资本市场和公众股东的要求？

**梁文锋：**

我们希望两者都要。如果 B 端收入继续增长，加上 C 端用户，公司距离净利润可能并不遥远。这样后续可操作空间会比较大。

最坏情况下，即使技术冻结在当前水平，全力卖 API、把服务做好，也可能支撑一家上市公司。我们处于一个杠杆高、发展快的领域，商业上未必有想象中那么难。

我们有更大的梦想，也有可以支撑公司的保底路径。
