近日，一份署名为“梁文锋投资者交流会”的长篇文字稿在社交平台流传。文本涉及 DeepSeek 的愿景、商业模式、技术路线、算力规划与组织方式，信息密度很高，也夹杂了大量口语重复、转录误差和未经独立核实的经营数字。

本文不逐字转载，而是按主题重新整理其中最值得关注的观点。需要特别说明：**下文是对流传文本的结构化归纳，不代表对会议真实性、具体数字或未来计划的独立确认**。涉及模型版本、发版时间、收入、融资和芯片数量的内容，都应以 DeepSeek 官方信息为准。

希望查看主要问答和完整论述脉络，可继续阅读：[《梁文锋投资者交流会全文整理版》](/posts/2026-07-24-liang-wenfeng-transcript)。

整场交流最核心的判断可以浓缩为一句话：

> DeepSeek 试图用“克制”换取更高的长期成功概率——不追求占有全部利益，而是聚焦 AGI 主线，把开源、低成本和商业化视为同一套战略的不同部分。

## 愿景不是口号，而是实际的资源分配方式

文本开篇花了很大篇幅讨论”愿景”。这里的愿景不是挂在墙上的价值观，而是公司在遇到真实利益时如何取舍：是否开源、如何定价、要不要抢夺 C 端流量、是否进入更多产品线，以及员工的时间应该怎样分配。

按照这份交流稿的表述，DeepSeek 最初并非以上市或利润最大化为目标，而是希望做一件”对人类有用”的事情。这一出发点后来形成了组织共识：目标是推动 AGI，而不是先成为超级 App；模型能力是主线，C 端和 B 端业务是技术进步带来的阶段性产物；不依赖严密 KPI 组织研究，而是依赖对方向的共同认可；是否做一件事，主要看它能否提高实现 AGI 的概率。

这也解释了文本中反复出现的”克制”。克制不是放弃商业利益，而是主动缩小目标边界。不把每一个眼前机会都变成必须争夺的战场，不因为暂时拥有流量就转向广告、电商或本地生活，也不因为视频生成是好生意就把它列为智能研究的主线。

当终局足够大时，眼前利益并不稀缺，真正稀缺的是团队注意力和长期成功概率。

## 开源与商业化为什么可以同时成立

交流稿对开源的解释分为两个层面。

第一层是价值观。既然希望 AI 能被更多人使用，开源就是愿景的自然结果，而不是竞争压力下的被迫选择。文本还强调，开源模型与自营服务所使用的模型原则上应保持一致，而不是公开一个较弱版本、私下保留更强版本。

第二层是商业判断。梁文锋在文本中的观点是：AI 市场足够大，任何公司都不可能独占全部价值。与其试图垄断，不如只获取合理利润，让生态中的其他参与者也有发展空间。

在这一逻辑下，开源不等于放弃 API 收入。理由有三点：部署门槛依然存在，权重可得，不代表企业能以同样的成本和稳定性完成推理服务；系统优化形成成本差异，模型架构、算子、编译器、集群调度和工程细节都会影响最终价格；托管服务仍然有价值，对多数用户而言，直接购买稳定 API 比自行组建团队部署更经济。

交流稿给出了一套非常具体的定价思路：按照设备在约十个月内收回成本来定价，而不是利用需求缺乏弹性去追求最高收入。文本称，某款模型曾因担心需求过大而定价较高，后来降至原价的四分之一，公司内部反而非常高兴。

无论具体回本周期是否准确，这套思想都值得关注：价格不是单纯的收入工具，也是组织愿景的外显。当模型已经足够便宜、继续降价也不会明显增加使用量时，价格才接近公司与社会都能接受的平衡点。

### 商业化是 AGI 路上的副产品，但不是可有可无

这份交流稿并没有否认商业化。相反，它把商业化视为公司长期生存的必要条件，只是不把商业化当作当前技术决策的第一目标。

文本将 C 端产品和 B 端 API 描述为通往 AGI 过程中自然产生的中间成果：模型既然已经训练出来，就可以用较小团队把能力提供给用户，而不需要为了获得收入改变主线。

这种策略有明显优势：技术研究可以持续产生可销售能力；不必过早押注生命周期很短的产品形态；更强的通用模型可以对具体应用形成”降维”优势；收入能够覆盖算力与研发投入，为长期研究提供保底。

但文本也给出了底线：DeepSeek 终究是一家公司，不是由政府或母体长期供养的实验室。即使未来技术进步停滞，仍可以转向把 API 服务做好，以现有用户和收入支撑企业经营。

更准确的表述不是”DeepSeek 不重视商业化”，而是：商业化必须服务于长期研究，而不能过早反过来定义研究方向。

## 从语言模型到持续学习：一条阶梯式路线

技术路线是这次交流中最重要的部分之一。文本把近年的 AI 发展描述为逐级叠加的阶梯：语言模型建立基础能力；思维链（CoT）让模型通过推理扩大可解决问题的范围；Agent 让模型调用工具、执行更长任务；持续学习让模型像员工一样在长期环境中积累经验；自我迭代让 AI 参与研发自己的下一代；具身智能最终进入现实世界，解决具体的人力需求。

在这一叙事中，今天的模型已经能在“上下文和指令完整”的局部任务里超过人类，但现实工作很少具备这个前提。新员工可以通过几个月工作理解公司中的人物、流程、历史和隐性规则，当前 AI 却需要每次重新获得上下文。

因此，持续学习被视为 Agent 之后最关键的瓶颈。它不是某一项单独技术，而是一组尚未解决的问题：模型如何获得长期记忆，如何从经验中更新，如何避免遗忘，如何判断哪些信息值得吸收，以及如何在真实任务中持续改进。

交流稿没有给出明确时间表，也坦承全球尚未找到真正有效的统一方案。更重要的是，它把持续学习看作一种研发杠杆：如果 AI 能长期参与 DeepSeek 内部工作，它就可以帮助研究人员开发下一代模型，AI 研究 AI 的过程也会从线性增长转向非线性加速。

这也是文本中一个颇具辨识度的产品判断：

> 下一代模型首先要对 DeepSeek 自己有用，能提高开发下一代模型的效率；在此基础上，它自然也可能对其他用户有用。

## 为什么世界模型和视频生成暂时不是主线

交流稿对世界模型、视频生成和多模态做了区分。

梁文锋在文本中并未否认这些方向的价值，而是认为它们在当前阶段不是提高智能上限的最短路径。视频生成可能是好产品、好生意，多模态也是面向用户的重要组件，但它们并不等同于“智能主线”。

在这套路线图中：

- **训练方法与持续学习**决定智能能力能否跨越下一个台阶；
- **搜索、多模态**更像扩展能力边界的组件；
- **视频生成、3D**可以创造商业价值，却未必直接提高通用智能上限；
- **具身智能**最终仍然重要，但最好在 AI 已经具备持续学习和自我迭代能力后再做。

这并不是对其他路线的否定，而是一种研发排序：先解决能够帮助后续研究的问题，再让更强的 AI 参与成本更高、工程更重的方向。

## 算力是中美差距的主要来源

在人才与资源之间，这份交流稿把算力视为更根本的约束。

文本认为，中国并不缺少聪明的研究人员，但算力不足会减少实验次数、限制模型规模，也会间接影响人才成长。研究人员无法反复验证想法，最终表现出来的“人才差距”有相当一部分其实来自资源差距。

交流稿对算力的态度可以概括为三点。Scaling 尚未见顶，至少对算力更受限的中国团队而言，还远未触及规模化训练的收益上限。资源决定可训练的模型规模，模型不是因为某个参数量已经”足够”才停在那里，而是由现实算力倒推可承受规模。全面追平不现实，重点突破更可行，当总算力存在数量级差异时，可以通过算法和系统效率缩短时间差，或在部分方向实现领先，但很难同时在所有维度超过资源更充足的团队。

文本将中国团队的典型路径概括为：晚一段时间，用更少算力复现美国前沿能力；未来的目标则是逐步缩短时间差，同时提高单位算力产出。

### 国产芯片的机会：生态可能先解决，产能更难

交流稿对国产 AI 芯片的态度相对乐观，但也区分了生态与产能两个问题。

过去国产卡的主要障碍之一是 CUDA 生态：硬件即使可用，算子、编译器和工具链不成熟，模型团队仍然很难高效训练和部署。文本认为，AI 辅助编程和新的高级编程语言正在削弱这种壁垒。

其中被重点提到的是 TileLang。按照交流稿的描述，DeepSeek 希望用更高级的语言降低算子开发成本，再把这套能力迁移到不同硬件上。相较于直接手写底层 CUDA 代码，这种方式代码量更少、开发更快，只需接受很小的性能损失。

如果高级编译层能够屏蔽硬件差异，国产卡的生态适配可能在较短时间内得到显著改善。但产能仍是更长期的约束。生态问题主要需要技术积累和市场信心；产能问题涉及先进制造、供应链和大规模交付；国产硬件即使能完成相同任务，也可能需要更多芯片和更高能耗；新卡本身落后于同期海外产品时，可使用生命周期也会更短。

文本的真实结论不是”国产卡已经追平”，而是：软件生态有机会加速补齐，硬件代际与供给规模仍需数年改善。

## 组织方式与竞争终局

### 组织的核心利益是团队稳定

交流稿把团队稳定称为 DeepSeek 最重要、甚至唯一不能让步的核心利益。

这里的逻辑是：资金、设备和其他资源最终都可以获得，但一支能够长期合作、共同面对研究挫折的团队无法快速重建。只要关键成员保持稳定，即使某次模型失败、进度推迟半年或一年，公司仍然可以继续尝试。

在具体管理上，文本描述了两条并行的工作线。从上到下的”正事”，例如发布新模型，需要全公司协作、明确分工。从下到上的自由研究，员工自己判断什么问题重要，自主探索，不设置统一 KPI。

理想状态下，“正事”不应占据研究人员全部时间，最好不超过一半，剩余时间由他们自由选择方向。公司也不鼓励普遍加班，一方面研究需要松弛环境，另一方面足够聚焦意味着本来就不应该有无限多的任务。

这种组织方式并非没有代价。随着人员规模扩大，完全松散的结构会妨碍跨团队推进。交流稿也承认，未来部分部门需要建立严谨层级，另一些研究部门则继续保持扁平。

它不是对传统管理的彻底否定，而是在寻找边界：**工程交付需要秩序，探索未知需要自由。**

### 大模型竞争最终比什么

当不同团队逐渐掌握类似能力后，交流稿认为长期差异主要落在三个方面：

1. **成本**：同样质量的服务，谁能以更低成本提供；
2. **时间**：谁能早几个月完成下一阶段能力；
3. **体验**：产品是否更稳定、易用，能否形成用户习惯。

其中，成本被放在第一位。开源会让知识更快扩散，模型能力也可能逐渐收敛，但系统效率、供应链、推理优化和工程组织并不会自动趋同。低成本既决定商业竞争力，也决定在有限算力下能否训练更大的模型。

这套观点进一步延伸出对行业格局的判断：基础模型公司不会无限增加，最终会收敛到少数几家；中国团队的结构性优势可能更多体现在成本和产品，而不是某种永久独占的算法秘密。

对于不同实验室之间的短期领先，文本同样保持克制。某家公司在 Coding Agent 上的先发优势，不等于能够永久占据绝对优势。OpenAI、Google、Anthropic 等团队都可能在不同阶段交替领先。

## 这份交流稿最值得记住的五个判断

抛开未经核实的数字、版本和时间表，这份长篇交流真正值得保留的是一套相互连接的思想：

1. **克制不是道德装饰，而是竞争战略。** 少拿一部分短期利益，可能换来更强的组织凝聚力、更广的生态支持和更高的长期成功概率。
2. **开源与商业化并不天然冲突。** 权重开放之后，低成本部署、稳定服务和工程效率仍然构成商业价值。
3. **持续学习可能是 Agent 之后的关键台阶。** 当前 AI 不只缺更长上下文，更缺在长期环境中积累和更新经验的机制。
4. **算力影响的不只是模型大小，也影响人才成长。** 缺少实验资源，会让算法探索、工程积累和研究人员训练同时变慢。
5. **组织设计必须服务研究目标。** 愿景负责凝聚方向，层级负责完成协作，自由时间负责探索未知，三者缺一不可。

这套叙事最终指向一种少见的公司定位：既不是纯研究机构，也不是由眼前市场需求驱动的产品公司，而是希望用商业化供养长期研究，再让长期研究不断产生新的商业能力。

它能否长期成立，取决于几个现实问题：技术能否持续领先、API 收入能否支撑投入、团队能否在规模扩大后保持稳定，以及“克制”在资本压力下是否仍能成为真实行动，而不只是一次交流中的表达。

但至少从这份文本呈现的逻辑来看，DeepSeek 的开源、低价、聚焦和组织文化并不是彼此孤立的选择。它们共同服务于同一个目标：**把有限资源集中到智能主线上，并尽可能延长团队继续探索的时间。**
